# Scope: manager65 live collector hardening

## Question

Can the old manager65 action-0x2B collector be replaced by a canonical-hash/module/HWND-bound, full-double-capture, widget-gated read-only collector without running the oracle?

## Allowed

- hash-bound static evidence and sealed prior artifacts
- offline fixtures, tests, collector/resolver implementation, independent review

## Forbidden

- VM/guest/debugger/breakpoint/process-memory operation in this unit
- input, capture, memory write, binary/resource patch, automatic retry
- VM lifecycle, server, protocol, or database change

## Acceptance

Pass only if the corrected strategy root and UI registry are separated, every semantic scalar and owned-HWND surface is captured twice, command 0x2B has exactly one fully eligible widget, live self-claims emit no activation point, all hardening deficiencies are mechanically absent, and independent review approves.
