## Evidence-state guard
- SEALED_ORACLE means hash-clean original EXE, clean resource manifest, no executable/resource/endpoint byte patch, no debugger memory writes, and host-only isolation without endpoint redirection.
- EXPLORATORY_REDIRECT means original EXE hash is still clean, but any IP/DNS/route override, hosts-file mapping, fake endpoint, local controlled endpoint, or host-only remapping redirects the hardcoded endpoint.
- PATCHED_EXPLORATORY means a disposable copy was modified, resources were modified, or the debugger wrote to process memory. It cannot promote original-client behavior.
