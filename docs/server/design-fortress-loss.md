# 요새 장갑·이동 요새 추진 파괴 설계

작성: Peppone Choi · 2026-11-03

체크리스트 252번의 「이동 요새 처리」. 사용자 결정(2026-11-03): 이동 요새는 일반 요새처럼 다루되 파괴될 수 있게 하고, 원작 규칙을 확인해 따른다.

## 원작 근거

- CD판 매뉴얼 p.46 「대지 공격」의 공격 목표(`evidence:manual`, CD판에만 있음):
  - 요새의 시설: 이동 요새를 공격할 때만 **추진 시스템**을 파괴할 수 있다.
  - 요새 자체의 **장갑**을 파괴할 수 있다. 장갑을 모두 파괴하면 그 안에 주류한 적 기함·함정 유닛은 모두 격침된다.
- 공식 사이트 전술 안내(2004-04): 전술은 자기 기함 격침, 또는 적 유닛·점령 대상 행성/요새가 없어질 때까지 계속된다.
- 매뉴얼은 장갑이 0이 된 요새 자체가 사라진다고 쓰지 않는다. 소유권은 지금처럼 육전(수비대 전멸)으로만 바뀐다.

## 제안 (`evidence:guess`, 수치는 확인 대기)

| 항목 | 제안 |
|---|---|
| 장갑 초기값 | 요새마다 10,000 |
| 대지 공격 피해 | 요새 대상일 때 공격 함정 하나당 장갑 500 (최대 10척 → 한 번에 5,000) |
| 장갑 0 | 요새에 주류(STATIONED)·계류한 수비 측 기함·함정을 모두 격침(기존 기함 격침·귀환 경로 사용). 요새는 남고, 육전으로 점령 가능 |
| 추진 시스템 | 이동 요새를 대지 공격하면 추진 파괴 표시. 이후 【移動】(U-26)을 거부 |
| 복구 | 소유 세력의 완전 수리 경로로 장갑·추진을 회복(별도 결정 전까지는 회복 없음) |
| 저장 | 거점 재고에 장갑·추진 상태를 추가(저장 형식 버전 증가) |

## 확인할 것

- 장갑 초기값·피해량.
- 장갑과 추진의 복구 방법.
