## 2. 범위 제안

- **1단계(이번)**: 査閲·叛意·謀議·参加·説得. 음모의 상태·참가자·충성도를 서버에 두고 저장한다. 원본 창에서 실행과 결과를 확인한다.
- **2단계(다음)**: 叛乱 실행. 반란 진영 인물·유닛·거점 전환, 반란 직무 카드, 진압과 종료, 승리 조건 연결이 들어간다. 인물·유닛 메시지의 반란 칸은 이 단계에서 따로 분석한다.

## 4. 사용자 결정 (2026-11-01)

1. 叛乱까지 한 번에 구현한다(단계를 나누지 않음).
2. 叛意 자격은 직무 보유 + 준장 이상이다. 수모자 한 명당 음모는 하나다.
