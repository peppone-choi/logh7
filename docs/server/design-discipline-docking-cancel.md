# 설계안: 군기 유지와 기항 예약 취소

작성: Peppone Choi · 2026-10-30 · 상태: **검토 대기**

체크리스트에서 설계 결정 때문에 멈춘 두 항목(`軍紀維持`, 40행 기항 취소·환불)의 제안이다. 승인 전에는 구현하지 않는다.

## 1. 군기 유지(軍紀維持)

### 1.1 근거

- 매뉴얼 커맨드 표(PDF p.68): MCP 80, 대기·소요 0. "군기 유지도를 높여 혼란 발생률을 낮춘다." `evidence:manual`
- 매뉴얼 p.28은 같은 이름을 첩보 커맨드 묶음(일제 수사·체포)의 분류어로도 쓴다. 이 절은 함장 카드의 부대 명령만 다룬다. `evidence:manual`
- 서버의 전술 혼란: 유닛 사기 0..100(기본 100), 피격마다 피해량만큼(최대 20) 감소, 20 이하이면 혼란(`TacticalCommandState.confused`). 매뉴얼 p.34의 "혼란한 유닛에는 발령 효과 없음"이 연결돼 있다. 수치는 기존 설계 추정이다. `evidence:guess`
- 군기 유지도의 범위·초기값·증가량·감소 규칙은 매뉴얼·클라이언트 어디에도 없다.

### 1.2 제안 `evidence:guess`

- **저장:** 부대(`OutfitStock`)별 군기 0..100, 기본 50. 저장 형식 판을 하나 올리고 이전 판은 50으로 읽는다.
- **명령:** 함장 카드 46. 항주 훈련 47과 같은 조건(자기가 지휘하는 현 위치 부대, 전술·지원 중 아님)에 MCP 80, 군기 +10(상한 100, 이미 100이면 무과금 거부).
- **효과:** 피격 때 사기 감소량에 `(150 − 군기) / 100`을 곱한다(내림, 최소 1). 군기 50이면 지금과 같고, 100이면 절반, 0이면 1.5배다. 혼란 기준(사기 20 이하)은 그대로다.
- **감소:** 게임 1일마다 군기 −1(하한 50). 높인 군기를 유지하려면 주기적으로 명령해야 한다. 50 아래로는 내려가지 않는다.
- **표시:** 원본에 군기 수치 UI가 없으므로 명령 창의 결과 문구에 "군기 n → m"을 보여 준다.

## 2. 기항 예약 취소

### 2.1 근거

- 매뉴얼에 기항(寄港) 예약을 취소하는 명령·규칙이 없다. 전술의 `停止命令`(p.55)은 실행 중인 함정/거점 명령의 취소이며 전략 이동과 무관하다. `evidence:manual`
- 워프 예약은 승인된 설계에서 "취소 없음, 전술로 CP 회복이 멈추면 실행을 미룸"으로 정했다(design-warp-academy-meeting.md 1.2).

### 2.2 제안 `evidence:guess`

- 워프와 같은 규칙으로 맞춘다. 기항 예약은 플레이어가 취소할 수 없고, 낸 CP도 돌려주지 않는다.
- 다만 예약 중에 실행 조건이 사라지면(목적지 소유권 변경, 진입 불가, 세션 종료) 실행 시점에 거부하고 원래 자리에 남긴다. 이때도 환불은 없다. 이 동작은 이미 구현된 경로를 문서와 체크리스트에 확정으로 기록하는 것이 주 작업이다.
- 체크리스트 40행은 이 규칙을 승인받아 기록하고, 실행 시 거부 경로를 원본으로 한 번 확인하면 완료로 처리한다.

## 3. 결정 요청

1. 군기: 부대별 0..100, 기본 50, 명령당 +10, 하루 −1(하한 50)
2. 군기 효과: 피격 사기 감소에 `(150 − 군기)/100` 배율
3. 기항 예약: 취소·환불 없음(워프와 동일), 조건 상실 시 실행 거부
