# 국가 정의와 국가별 체계

작성: Peppone Choi ([peppone-choi](https://github.com/peppone-choi)) · 2026-11-05

사용자 결정에 따라 국가 ID, 국가 계열, 원본 클라이언트 표시 코드를 분리한다. 현재 구현의 두 진영을 늘리는 조건문을 계속 붙이는 대신 국가 정의를 등록하는 방향으로 이행한다. 이 문서는 현재 이행 경계와 확정된 규칙을 설명한다. 일정·작업 상태의 단일 원천은 Linear와 구현 체크리스트다.

## 확정 규칙

- 계열은 동맹계·제국계·신제국계를 구분한다. 기존 제국은 연도가 바뀌었다고 신제국 계열이 되지 않는다. 사용자 제공 환산은 제국력 = 우주력 −309, 신제국력 = 우주력 −798이다. 추가 국가의 독자 기원은 국가별 역법 재정의로 다룬다.
- 무소속은 국가 ID 0으로 만든 가짜 국가가 아니라 소속 국가가 없는 인물 상태다. 건국의 시작 조건은 **무소속이며 지배 거점 한 곳을 확보한 인물**이고, 그 거점을 수도로 삼는다. 소속·거점 지배·수도·국가 ID 발급을 월드 액터의 한 명령으로 처리해야 한다.
- 국가별 커맨드·계급·직위·작위는 계열 기본 체계를 상속하고 국가가 재정의할 수 있다. 기존 명령 CSV와 직위 자료를 재사용하고, 원본 카드 번호를 새 국가의 영구 ID로 삼지 않는다. 명령 처리기는 코드로 검증된 동작을 실행하고 비용·대기·소요·권한 등의 정의는 데이터로 분리한다.
- 함정 스타일은 국가 계열과 별개다. 제국계·동맹계 스타일로 시작하되 국가가 선택할 수 있고, 이후 스타일과 모델·텍스처 묶음을 등록해 추가한다. 함선의 전투 규칙과 외형을 같은 식별자로 고정하지 않는다.
- 문장·깃발·지도 아이콘은 국가별 자산 프로필로 관리한다. 자산 팩 ID·버전·파일 종류·상대 경로·해시를 저장하며 원본 게임 저작물은 커밋하지 않는다.
- 국가 색상은 대표색·보조색·지도·함대의 RGB 재정의다. 각 값이 NULL이면 원본 자산색을 유지한다. 아군/적군·반란·혼합 소유 표시는 별개로 유지한다.
- 통화도 별도 정의다. 이름·기호·소수 자릿수와 국가별 통화를 관리하고, 잔액은 통화 ID와 최소 단위 정수 금액으로 식별한다. 기존 회계 단위를 실제 통화 환율로 확정한 근거는 없다([현재 경제 설계](planet-economy.md)). 통화 이행 시 기존 잔액 보존 기준을 명시하며 임의 환율을 만들지 않는다. MCP/PCP는 통화와 구분한다.
- 번역은 안정된 메시지 키로 모으고 국가별 용어와 연결한다. 편집 화면에서 검색·수정·미리보기·초안 저장·게시를 지원하며 변수/printf 서식을 검증한다. 게시 버전을 원본 리소스 바인딩과 함께 배포해 문구 변경마다 DLL을 다시 빌드해야 하는 구조를 해소한다.

## 현재 구현 경계

- 임명 저장 경계도 `targetCountry`를 사용하며 `AppointmentTransactionTest` 4개가 통과했다. 중앙 직위 전체 규칙에 대해 지급/권한/직위가 함께 확정되거나 저장 실패 시 모두 유지되는지 검사한다.
- 캐릭터 파일의 각 계정 값은 다음 저장부터 `v2:generated|original:국가ID|-:함정스타일ID:기존본문hex`로 기록한다. 국가 ID는 양수 정규 정수, 무소속은 `-`다. 생성·추첨·망명·이월·은퇴가 같은 원자 파일 교체를 쓰며 국가·스타일을 별도 파일에 나눠 확정하지 않는다. 구형 hex/`original:`과 응모·마감 시각은 계속 읽는다. 읽기만으로 파일을 이행하지 않으며 구형에만 종전 기함 보정을 적용한다. v2의 다른 스타일 기함은 화면 진영 번호로 다시 바꾸지 않는다. 잘못된 버전·국가·스타일은 기존 진영으로 대체하지 않고 적재를 거절한다. **v2로 저장한 캐릭터는 이전 서버에서 열 수 없으므로 업그레이드 전 전체 백업을 보존하고, 하위 버전 복귀에는 그 백업 전체를 복원한다.** 정상 플레이 저장은 이번에 이행하지 않았다.
- `StrategicIdentity`의 소속도 실제 `CountryId?`다. 게이트웨이는 계정·캐릭터 ID·세대가 맞는 현재 항행 상태의 국가/스타일을 우선하고, 아직 입장하지 않은 인물은 등록 레코드를 쓴다. 임명·해임 대상, 승진 래더/정원, 지지 자금·체포 허가·황위 계승·의장 후보를 실제 국가로 구분한다. 기존 국가 2/3 정치 규칙은 신규 국가/무소속 정치가에 자동 적용하지 않는다. 승진 기함은 대상자의 함정 스타일을 따른다. 다음 세대 이월에도 세션 종료 시 실제 국가와 스타일을 보존한다. 신규 국가의 가입 입력·국가별 직무/계급/정치 체계 연결은 계속 미완료다.
- 캐릭터 소속 검사(2026-11-06): 관련 엔진 73개·게이트웨이 45개와 앱 배포본 생성을 통과했다. 실제 국가 1/4/42·무소속의 타국 임명/해임·승진/래더·지지 자금·온라인/오프라인 체포 허가·황위/의장 후보를 구분하고 국가 2 인물의 동맹형 승진 기함을 확인했다. 원본 실기(`work/character-country-20261106`): 정지 QA 백업 12개 파일을 별도 폴더에 복원하고 생성 등록 경로로 기존 캐릭터 파일을 v2로 저장했다. 구형 Fresh 레코드의 국가·스타일·본문은 재개방 대조에서 유지됐고 원본 제국 전략 진입, 서버 재시작 뒤 재접속과 기존 재무 직무의 예산 창에서 국고 85879607·지방 금고 8172839·완료 이체 50000·MCP 1000을 확인했다. 양쪽 실행의 무음·Job 0 정리·활성 화면/입력 및 원본 해시 보존을 확인하고 QA 서버도 종료했다. 신규 국가 화면의 실기는 아니다.
- 직위 공통 정책(`OrganizationalOfficePolicy`, `BaseOfficePolicy`, `NationalOffice`, `FleetOffice`, `LogisticsOfficePolicy`)은 거점·부대의 실제 소유국으로 기존 국가 2/3의 직위를 판정한다. 외국 부대가 같은 함정 스타일을 써도 권한을 받지 않으며, 같은 국가의 다른 스타일은 직위를 잃지 않는다. 국가 1/4/42가 섞인 자료를 조회할 때 국가를 기존 `Power`로 변환하며 예외를 내지 않고 해당 기존 직위를 비활성으로 판정한다. 점령된 수도의 중앙·병참 직위도 비활성화하며 잘못된 수도 직위 입력의 검증은 유지한다. 이 범위는 기존 직위의 소유국 검사다. 임명/해임 대상의 실제 국가는 위 캐릭터 경로로 연결했고, 국가별 직무 정의·입장/명령자 국가 입력 확장·전체 임명 권한과 신규 국가 플레이 이행은 남는다.
- 직위 소유국 검사(2026-11-06): 혼합 국가 자료의 조회/임명 예외를 먼저 재현했고 관련 엔진 46개가 통과했다. 기존 조직표 121행의 임명·해임·사임 검사와 신규 국가/비국가 소유자·양쪽 함정 스타일·타국 직위 미공유·임명 거부 시 CP/저장 불변을 확인했다. 기존 국가 2의 다른 스타일 부대는 국가 2의 직위를 유지한다. 저장 형식은 변경하지 않았다.
- 직위 회귀 실기(`work/office-country-20261106`): 별도로 복원한 시험 저장에서 Fresh의 기존 재무 직무 카드 8로 원본 예산 창을 열고, 서버 재시작/재접속 뒤에도 같은 직무와 완료 이체 50000·MCP 1000을 확인했다. 이전 라이브러리로 집계한 활성 직위 1건과 중앙/병참/거점/부대 직위 표, 국가·함정 스타일·창고 연결·인물 위치/기함·예산 영수증을 정지 저장에서 대조했다. 날짜가 1월 1일에서 2일로 넘어가며 생산 정산 일수도 0→1이 됐고 금고에 일일 정산이 반영됐다. 두 원본 실행은 무음·Job 0·원본 해시 보존을 확인했고 QA JVM도 종료했다. 입력 백업 12개 파일을 재검증했다. 이 실기는 기존 국가 2의 재무 직무 확인이며 새 국가 직위의 원본 실기는 남는다. 주 서버 저장·비밀 환경 파일·Docker는 변경하지 않았다.
- `config/countries/`의 역법·계열·국가 CSV와 서버의 `CountryCatalog` 로더가 정의를 분리한다. 현행 국가 2/3을 제공하며 새 국가와 계열 참조·중복 식별자·원본 표시 코드 범위를 검사한다.
- 참가자 소속과 제외 이력은 양수 `CountryId` 하나로 저장하고 무소속은 NULL로 보존한다. 참가·재접속·제외 후 복귀·망명은 실제 ID를 비교한다. `SessionCodec` 형식 2부터 ID/무소속을 쓰고, 형식 3은 국가 명부·국가별 탈락·최종 생존국도 저장한다. 형식 1의 `EMPIRE`/`ALLIANCE`는 기존 국가 2/3으로 읽으며 형식 1·2의 정규 재인코딩과 구·신 저널 혼합 재생을 유지한다. 새 체크포인트·추가는 형식 3이다. 기록한 저장본은 이전 서버에서 열 수 없으므로 업그레이드 전 저장 묶음 전체를 백업해야 한다.
- `WorldCommand.Join`은 실제 국가 ID/무소속을 받으며 원작 `Power` 오버로드도 유지한다. 2026-11-07 추가 국가의 생성·입장·복구 제한은 아래 [추가 국가 실제 입장과 국가별 패배](#추가-국가-실제-입장과-국가별-패배-2026-11-07) 범위로 확장했다. 알 수 없는 국가나 지원하지 않는 표시·함정·직위 체계는 복구 기록을 쓰기 전에 거절한다. 계열·외형으로 다른 국가를 제국/동맹으로 대신 취급하지 않는다.
- 이행 확인(`work/country-session-20261105`): 로컬 엔진 966개·저장소 181개 통과, PostgreSQL 실DB 검사 1개는 로컬에서 생략했고 별도 CI 실DB에서 통과했다. 이전 신규 유저 시험 저장의 사본을 저장소 API로 새 경로에 내보내 전체 항행·재고 값의 동일성을 확인하고, 원본 일반 UI에서 Fresh의 선택·전략 진입·얼굴·능력치·행성 오딘·제국력 486년 표시를 확인했다(`run-02`, `legacy-empire-play.png`). 클라이언트는 시작 전 무음·Job 0 정리·원본 해시 보존을 통과했다. 초기 서버의 긴 세션명·다른 경로 소유 표식 때문에 시작이 거부됐고, `run-01`은 연결 실패로 별도 보존했다. 정상 플레이 저장과 비밀 환경 파일은 접근하지 않았다. 신규 국가·무소속의 실제 플레이는 이번 실기 범위가 아니다.
- 국고 원장은 `Map<CountryId, Long>`으로 저장한다. 세금·예산 지원·무역·정보 매입·페잔 보조금·함대 유지비와 재정 직위의 금고 조회가 같은 원장을 쓴다. 국가색·계열·원본 표시 코드로 잔액을 합치지 않는다. 기존 저장의 2/3 계좌는 금액을 그대로 읽고, 추가 국가 계좌가 있을 때만 `LOGH7-STOCK-39`로 기록한다. 39는 양수 ID·중복·음수·건수 제한을 검사하며 이전 형식으로 위장한 추가 국가 계좌를 거절한다. 세계의 위치·재고와 한 원자 저장으로 확정하고 정의 DB에 따로 기록하지 않는다. 현재 거점·부대 소유권과 재정 명령의 직위/상대국 규칙은 기존 두 국가 범위이므로 새 국가의 실제 세금·함대·무역 권한까지 이행한 것으로 세지 않는다. 통화별 잔액·환율 변환도 아직 적용하지 않는다.

### 세계의 초기 소유국과 징발 판정 (2026-11-07)

작성: Peppone Choi ([peppone-choi](https://github.com/peppone-choi)).

세계 파일의 `schema=3`에서 `base.0.owner=C:42`처럼 거점별 초기 소유국을 지정한다. 번호는 같은 파일의 `base.0.id`를 가리키는 행 번호이며, 국가 ID는 양의 정수의 정규 표기다. 비국가 소유는 `U`(미정)·`N`(중립)·`P`(해적)로 구분한다. 국가 ID1과 중립은 다르다. 생략한 거점과 기존 형식1/2는 원래 성계의 `power`로 초기 소유를 정한다. 형식3도 국가별 시작 위치를 지원하며, 형식1/2에 새 소유 필드를 넣거나 존재하지 않는 거점 행·손상된 소유 값을 쓰면 거절한다.

초기 소유는 현재 점령 상태와 별도로 보존한다. 새 세대의 재고만 초기 소유를 적용하고, 같은 세대의 저장 재고는 재시작해도 현재 소유국을 유지한다. 재고 없이 판정하는 항행/귀환·격침 복귀·전력 집계와 초기 거점/시설 표시도 실제 초기 소유를 쓴다. 옛 두 국가의 기본 부대는 초기 소유와 현재 정규 소유가 모두 맞는 거점에만 배치한다. 초기 소유를 바꾼 거점이 옛 수도 이름을 갖고 있어도 외국의 수도를 막 함락한 것으로 처리하지 않는다. 새 국가의 부대·수도 편집과 전체 입장은 남은 작업이다.

### 지상전·육전 위치·함대 유닛 조회의 실제 국가 (2026-11-07)

## 거점 소속과 전략 지도 표시 (2026-11-07)

보존됐으며 소유 클라이언트 Job과 시험 서버·DB 종료를 확인했다.
함대 접촉/척수의 원본 두 진영 집계와 국가별 얼굴·출신 규칙은 미완료다.
운영 웹의 업로드 이미지 등록과 전략·전술 문양 연결은 [국가 이미지 운영](../ops/country-images.md)을 참고한다.
