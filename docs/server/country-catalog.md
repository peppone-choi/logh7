# 국가 정의와 국가별 체계

작성: 최병호 · 2026-11-05

사용자 결정에 따라 국가 ID, 국가 계열, 원본 클라이언트 표시 코드를 분리한다. 현재 구현의 두 진영을 늘리는 조건문을 계속 붙이는 대신 국가 정의를 등록하는 방향으로 이행한다. 이 문서는 현재 이행 경계와 확정된 규칙을 설명한다. 일정·작업 상태의 단일 원천은 Linear와 구현 체크리스트다.

## 확정 규칙

- 계열은 동맹계·제국계·신제국계를 구분한다. 기존 제국은 연도가 바뀌었다고 신제국 계열이 되지 않는다. 사용자 제공 환산은 제국력 = 우주력 −309, 신제국력 = 우주력 −798이다. 추가 국가의 독자 기원은 국가별 역법 재정의로 다룬다.
- 무소속은 국가 ID 0으로 만든 가짜 국가가 아니라 소속 국가가 없는 인물 상태다. 건국의 시작 조건은 **무소속이며 지배 거점 한 곳을 확보한 인물**이고, 그 거점을 수도로 삼는다. 소속·거점 지배·수도·국가 ID 발급을 월드 액터의 한 명령으로 처리해야 한다.
- 국가별 커맨드·계급·직위·작위는 계열 기본 체계를 상속하고 국가가 재정의할 수 있다. 기존 명령 CSV와 직위 자료를 재사용하고, 원본 카드 번호를 새 국가의 영구 ID로 삼지 않는다. 명령 처리기는 코드로 검증된 동작을 실행하고 비용·대기·소요·권한 등의 정의는 데이터로 분리한다.
- 함정 스타일은 국가 계열과 별개다. 제국계·동맹계 스타일로 시작하되 국가가 선택할 수 있고, 이후 스타일과 모델·텍스처 묶음을 등록해 추가한다. 함선의 전투 규칙과 외형을 같은 식별자로 고정하지 않는다.
- 문장·깃발·지도 아이콘은 국가별 자산 프로필로 관리한다. 자산 팩 ID·버전·파일 종류·상대 경로·해시를 저장하며 원본 게임 저작물은 커밋하지 않는다.
- 통화도 별도 정의다. 이름·기호·소수 자릿수와 국가별 통화를 관리하고, 잔액은 통화 ID와 최소 단위 정수 금액으로 식별한다. 기존 회계 단위를 실제 통화 환율로 확정한 근거는 없다([현재 경제 설계](planet-economy.md)). 통화 이행 시 기존 잔액 보존 기준을 명시하며 임의 환율을 만들지 않는다. MCP/PCP는 통화와 구분한다.
- 번역은 안정된 메시지 키로 모으고 국가별 용어와 연결한다. 편집 화면에서 검색·수정·미리보기·초안 저장·게시를 지원하며 변수/printf 서식을 검증한다. 게시 버전을 원본 리소스 바인딩과 함께 배포해 문구 변경마다 DLL을 다시 빌드해야 하는 구조를 해소한다.

## 현재 구현 경계

- `config/countries/`의 역법·계열·국가 CSV와 서버의 `CountryCatalog` 로더가 정의를 분리한다. 현행 국가 2/3을 제공하며 새 국가와 계열 참조·중복 식별자·원본 표시 코드 범위를 검사한다.
- 같은 자료에서 `tools/l10n/country_catalog.py`가 호환 DLL의 역법 표를 생성한다. HUD의 정상 갱신과 이동 대기 중 표시가 이 자료를 사용한다. **신제국력은 신제국 계열 자료로만 선택한다.** 현재 플레이 가능한 소속은 기존 두 국가이므로 신제국·신규 국가의 실제 입국/생성 확인으로 간주하지 않는다.
- `V1__national_definitions.sql`은 PostgreSQL용 국가·계열·역법·통화·체계·함정 외형·국가 자산·소속·영토·수도·통화별 계좌와 번역 초안/게시 버전의 경계를 정의한다. 공유 CSV와 참조 제약은 PostgreSQL CI 시험 대상으로 둔다. 기존 라이브 파일 저장소에 자동 적용하지 않는다.
- 현재 번역은 `l10n/*.ko.json`·TSV와 생성 카탈로그, 일부 C++ UI 리터럴을 사용한다. `tools/l10n/editor.html`은 메시지·상수·EXE·Windows UI 번역 JSON을 열어 검색·수정·텍스트 미리보기·저장/복사본 다운로드하는 초기 편집 도구다. 원본 해시와 메타데이터를 보존하고 변수·서식·금지 문자 변경을 거부한다. 이번 문구 수정도 DLL 카탈로그 재생성이 필요하다. TSV·NPC 이름·C++ 리터럴의 통합 편집과 DB 기반 게시/배포·재빌드 없는 갱신은 아직 구현하지 않았다.

추가 국가의 가입/건국을 활성화하려면 현재 `Power`의 두 진영 열거형, 소속·계좌·거점·부대·직책 권한 판정, 저장 복원과 원본 표시 어댑터를 실제 국가 ID로 이행해야 한다. 원본 국가 코드 0~4는 표시 한계이며 국가 정체성이나 외교 판정으로 쓰지 않는다. 같은 제국형 외형을 쓰는 두 국가가 같은 소유권·창고·직위 권한을 공유해서는 안 된다.

건국의 DB 기록과 기존 월드 저널을 독립적으로 확정하는 방식은 중간 실패 시 어긋날 수 있으므로, 실제 건국 명령은 저장 이행·재시도·복구 경계를 마련한 뒤 연결한다. PostgreSQL의 [외래 키·고유 제약](https://www.postgresql.org/docs/18/ddl-constraints.html)과 [트랜잭션 잠금](https://www.postgresql.org/docs/18/explicit-locking.html)은 그 무결성을 보조하며 게임 내 지배권 검사를 대신하지 않는다.
