# 황위 계승과 계승 내전

작성: Peppone Choi · 2026-11-02

## 근거와 결정

- CD판 매뉴얼 p.38은 "쿠데타 외 사유로 황제가 공석이면 정치가 래더 1위가 새 황제"라고만 한다(`evidence:manual`). 원작 소설에서는 계승을 두고 내전(립슈타트 전역)까지 일어난다.
- 사용자 결정(2026-11-02):
  - 계승 서열: 지명 후계자가 먼저이고, 그다음은 작위 순이다.
  - 공백: 두지 않고 즉시 즉위한다.
  - 내전: 2순위 후보가 계승을 거부하면 반란을 일으킬 수 있다.
- 아래 세부 수치와 처리는 모두 `evidence:guess`다.

## 계승 서열 (`SuccessionActions.order`)

- 대상은 살아 있는(전사하지 않은) 제국 인물 중 반란 진영이 아닌 사람이다.
- 순서: ① 황제가 지명한 후계자 ② 작위(공작→후작→백작→자작→남작→제국기사→작위 없음) ③ 영향력 ④ 공적 ⑤ 낮은 ID.

## 즉위

- 황제가 전사하거나 직위에서 제거되면(`StrategyActions.clearOffices`) 공석 표시가 남는다. 다음 일일 정산에서 서열 1위가 즉시 즉위한다.
- 처음부터 비어 있던 황제 자리는 30일 경계(`PoliticianLadder.monthly`)에서 같은 서열로 채운다.
- 제국 반란이 진행 중이면 즉위를 미룬다. 결과는 반란의 승패에 맡긴다.
- 즉위하면 새 황제, 2순위 후보(라이벌), 즉위 시각을 기록하고, 지명 후계자는 비운다.
