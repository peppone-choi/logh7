# 설계안: 나이 효과와 기함 격침 경험치 감소

작성: Peppone Choi · 2026-10-30 · 상태: **검토 대기**

체크리스트 178행(능력 성장·경험치·연령 …) 가운데 CP 경험치는 구현했다([CP 경험치](design-cp-experience.md)). 남은 나이 효과와 격침 감소를 구현하기 전에 쓰는 설계다. 승인 전에는 구현하지 않는다.

## 1. 근거

- 매뉴얼 W p.15: 성장은 "잠정 사양"이다. 젊은 캐릭터는 매월 능력이 오를 가능성이 있고, 장년 캐릭터는 매월 내려갈 가능성이 있다. 증감 모두 일정 값까지만. `evidence:manual`
- 2004-05-20 패치: 능력 51 이상은 나이가 많을수록 감소할 수 있다. 격침 시 경험치 0. `evidence:manual`
- 2004-06-11 패치: 어린 캐릭터의 시간 성장과 노화 면제. 기함 격침 경험치 감소를 계급별 차감으로 바꿈(황제·원수 50, 상급대장~준장 30, 대령~소령 10, 대위~소위 5, 조장~이등병 1). 경험치가 0인 능력은 감소할 수 있다. 05-20의 "경험치 0"과 동시에 적용하지 않는다. `evidence:manual`([패치 이력](../manual/09-patch-history.md))
- 캐릭터 생성의 나이는 18~59, 생일은 월·일로 저장된다. 달력은 30일×12개월이다. `evidence:client`
- 나이 경계, 월간 확률·폭, 상하한, 격침 감소를 받는 능력은 어디에도 없다.

## 2. 제안 `evidence:guess`

### 2.1 나이 증가

- 게임 달력에서 생일(월·일)을 지날 때마다 나이 +1. 세션 이월 규칙(60세 도달 등)은 세션 생애주기 작업에서 다룬다.

### 2.2 월간 나이 효과

매 게임 월 1일 정산에서 인물마다 한 번 판정한다.

| 나이 | 효과 |
|---|---|
| 18~29 | 25% 확률로 무작위 능력 하나 +1 (상한 100) |
| 30~44 | 변화 없음 |
| 45 이상 | 51 이상인 능력이 있으면 (나이−44)×2% 확률(최대 30%)로 그중 무작위 하나 −1 (하한 50) |

- "증감 모두 일정 값까지"는 상한 100, 노화 하한 50으로 해석한다.
- 난수는 세션 시드·인물 ID·게임 월로 정해 재시작해도 같은 결과가 나오게 한다(체크리스트 197행).
- 마지막 정산 월을 저장해 서버가 꺼져 있던 달은 최대 12개월까지 따라잡는다.

### 2.3 기함 격침 경험치 감소

- 기함이 격침되면 계급별 차감값(50/30/10/5/1)을 **8개 능력 모두**의 경험치에서 뺀다.
- 경험치가 모자라면 능력 −1, 경험치는 100에서 남은 값을 뺀 값이 된다(내림 차입). 능력 하한은 1.
- 계급 구간은 기존 계급 번호(0~20)를 매뉴얼 구간에 대응시킨다.

## 3. 결정 요청

1. 월간 나이 효과의 경계·확률(18~29 25% 상승, 45 이상 노화, 상한 100·노화 하한 50)
2. 격침 감소를 8개 능력 모두에 적용할지, 무작위 한 능력에만 적용할지
3. 경험치가 모자랄 때 능력을 1 내리는 차입 방식
