## 오픈까지의 최단 경로

"가능한 한 빠른 오픈" 목표에 맞춘 순서:

1. **P1 핵심**: 격리 VM → 접속 경로·프레이밍·암호화 판정 (LOGH-5, 7, 9, 10)
2. **P2 전체**: 스텁 → 로그인 → 서버 목록 → 캐릭터 생성 (LOGH-17~25)
3. **P3 최소 루프**: 시계·시드·카드/CP·이동·채팅 (LOGH-27~30) — 여기까지면 "접속해서 돌아다니며 대화" 가능
4. **P6 로컬 알파**: Compose 배포·백업 (LOGH-42, 43) → **내부 알파 오픈(목표 2026-12-20)**
5. P3 나머지(인사·작전·병참·전술) + P4 한글화 → **오픈 베타(목표 2027-01-31)**
6. P5 미구현 기능은 베타 이후 순차
