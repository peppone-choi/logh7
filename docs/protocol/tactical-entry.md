# 전술 진입 연결 중간 상태

작성: 최병호 · 2026-10-28

## 구현과 확인

- `evidence:manual` [전술 규칙](../manual/06-tactics.md)의 적대 세력 접촉 조건을 현재 그리드의 배치 함대·기함·거점 소유권과 연결했다. 접촉 중에는 전략 이동과 CP 회복을 제한하고, 접촉이 끝날 때 회복 시점을 재설정한다. 별도의 영속 전술 인스턴스는 아직 없다.
- `evidence:client` 현재 그리드 `0317`의 마지막 바이트가 전술 여부다. `0f1f`는 상태 `u8`와 그리드 `u32`이며 메모리 정렬 패딩을 보내지 않는다(`0048cb80`).
- `evidence:client` `0337`은 그리드 `u16`·인물 수 `u16`·인물 ID 배열이다(`00421740`). `033b`는 유닛 수 `u16`과 47바이트 레코드다(`00421f80`). 레코드는 ID·사기·혼란·지휘 인물·좌표/방향·전대장·전대 좌표/방향·색적 상태 순서다.
- `evidence:client` `0349`는 개수 `u16`과 20바이트 위치 레코드(ID와 네 개의 float), `034b`는 개수 `u8`과 16바이트 거점 위치 레코드다(`00426360`, `004268b0`). 현재 전장에 속한 ID만 반환한다.
- `evidence:guess` 초기 위치와 전대 배치는 임시 규칙이다. 실제 저장된 현역 함정 ID·함종·잔존 척수·부대·물자를 사용하지만, 전술 좌표·방향·지휘권·색적 상태를 영속 전투 모델로 완성하지 않았다. NPC 임무와 전투 손실 반영도 미완료다.

## 원본 두 개 시험

별도 QA 월드의 2017 그리드에 제국 함정 40유닛, 동맹 함정 40유닛, 동맹 플레이어 기함 두 척을 배치했다. 원본 실행 파일은 수정하지 않았다. 정상 플레이 서버의 월드는 이 시험에 사용하지 않았다.

- `run-22`와 `run-23`: 첫 원본은 전술 HUD에 진입했지만 다른 플레이어가 합류할 때 `005e015a`의 모델 해제 경로에서 종료됐다. 전략용 `0b09`/`0b0a` 인물 갱신이 전술 화면에도 전달됐다. `0325`는 전체 유닛 목록을 교체하며, `0b0a`는 살아 있는 전술 모델을 재구성한다. 전체 목록을 다시 보내는 것만으로 충돌이 없어지지 않았다.
- `run-24`: 전술 화면의 합류/퇴장 알림을 원본 `0f1f` 재진입 경로로 바꾼 뒤 두 원본 모두 전술 HUD에 진입했다. 메모리에서 두 인물·기함 ID와 82개 전술 유닛의 함종·진영·지휘 인물을 확인했다. 함정 위치 조회가 반복되는 것도 확인했다. 이 시험만으로 장시간 안정성이나 전투 완료를 판정하지 않는다.
- 검사는 엔진 458개·프로토콜 94개·게이트웨이 160개 통과. 추가 회귀 검사는 두 번째 계정의 합류 시 재진입 알림과 전체 전장 목록 보존, 전장 밖 ID 배제, 압축된 전술 레코드의 바이트 위치를 확인한다.

캡처·실행 결과는 `work/native-multiplayer-20261028/`와 작업 트리의 같은 이름 디렉터리에 보관한다. 전체 전술 완료 체크는 유지하지 않는다.

## 이어서 해결할 사항

1. HUD의 `NO TABLE`, 초기화되지 않은 패널, 0으로 표시되는 에너지와 명령 비활성 상태. `033f` 지휘/에너지·방어막/충전 데이터와 전술 명령 표를 연결해야 한다.
2. 원본에서 에너지 배분·이동·공격·철수 명령을 실행하고 두 클라이언트가 같은 결과를 받는지 확인한다.
3. 임시 배치를 영속 전술 인스턴스로 옮기고 지휘권·CRC·색적·서버 시계·NPC·손상·격침·점령·복귀를 연결한다.
4. 전략에서 실제 접촉→전술 진입→종료→전략 복귀, 동시 참가·재접속·서버 재시작 시험을 완료한다.

현재 코드는 전술 연결 작업 브랜치에 보관하며 정상 플레이용 런타임에는 적용하지 않는다. 전술 화면 도달을 게임 플레이 완성으로 취급하지 않는다.
