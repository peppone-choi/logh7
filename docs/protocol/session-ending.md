# 세션 종료 통지 연결

작성자: Peppone Choi · 2026-10-29

## 현재 범위

저장된 수도/성계 소유권의 종료 판정은 [세션 시계](../server/session-clock.md#2026-10-29-점령-결과와-세션-종료-연결)에 연결했다.
`SessionEndingMessages`는 원본의 `035a NotifyEnding` 전송 형식을 제공한다.
gateway의 실제 종료 발행과 호환 모듈의 결과 패널을 연결하고 두 원본의 수도 함락 경로를 확인했다. 보상 저장은 미완료다.

gateway는 저장된 최종 결과를 먼저 암호화 전송하고 현재 세대의 결과 조회 접속을 유지한다.
다음 세대에서는 이전 접속을 닫는다. 결과 보관·보상·재접속 조회·다음 세션의 인물 이월은
아직 연결해야 한다. 접속을 유지하는 것만으로 세션 완주 전체를 완료 처리하지 않는다.

## 원본 형식

CD 클라이언트 바이너리 수신 `004301d0`, 텍스트 수신 `00431460`, 진단 출력
`00433250`, 월드 디스패처 `004ba2b0`의 `035a` 분기 및 후처리 `004beb30`을
대조했다. 수신 객체 크기는 `0x434`지만 실제 전송은 아래 가변 길이이며 객체의
정렬 패딩·고정 배열 여백을 보내지 않는다. `evidence:client`

| 순서 | 전송 값 |
|---|---|
| 1 | `0323`과 같은 캐릭터 레코드(헤더 제외, together까지) |
| 2 | 이전/최종 평가·이전/최종 명성 각각 u32, 우호도 u8 |
| 3 | 세션 ID u16, 상태 u8, 이름·시작일 문자열, 게임 시각 u32 |
| 4 | 정규 두 세력 레코드. 앞에 세력 개수 없음 |
| 5 | 전체 종료 통계 개수 u8(0 또는 1), 있으면 통계 |

각 세력은 세력 u8·시작 연도/인물 수/거점 수 각각 u32·종료 레코드 개수
u8(0 또는 1) 순서다. 종료 레코드는 대표자 문자열·대표자 카드 u16·승리 종류
u8·인구 지배/전력 우위/쿠데타/제국 인물 위치 값 각각 u8·통계다.
통계는 행성 수/요새 수 각각 u16·인구/함정 수/육전대 수 각각 u32다.
세력 2·3을 각각 한 번 보내며 인코더는 세력 순서로 정렬한다. `evidence:client`

문자열은 UTF-16 코드 단위 수 u8 뒤 빅엔디언 UTF-16이다. 비어 있으면 수 0,
비어 있지 않으면 끝 NUL까지 포함한다. 세션 이름·대표자 이름은 최대 본문 12단위,
시작일은 최대 64단위다. 정수는 네트워크 바이트 순서로 보낸다. 네 조건 필드는
메모리상의 정렬 여백 없이 바로 통계에 이어진다. `evidence:client`

승리 종류 코드와 세션 상태 값의 의미, 최종 평가/명성의 지급 공식은 이 인코더에서
추측하지 않는다. 숫자 폭·문자열 한계만 검증하며 실제 계산·등급 대응은 후속 연결이다.
매뉴얼의 결정적/한정적/국지적 승리·패배 조건과 원본 코드 대응을 확인해야 한다.

## 저장된 종료 시점의 승패·통계 집계

`WorldSnapshot.result`는 종료가 저장·공개될 때 `SessionResults.fromWorld`로 현재
소유권·경제·유닛을 집계한다. 계류/활동 중인 함정은 살아 있는 ID만 세며 부대의 합계와
실제 ID를 중복 합산하지 않는다. 창고/미배치 완편 유닛·끝수 스택은 각각 선택 가능한
유닛으로 센다. 건조 중 수량은 제외하고, 현재 세대의 오프라인/구형 기록의 개인 기함도
포함한다. 행성·요새와 인구는 현재 소유권을 사용하며 중립/반란 인구는 전체 분모에
포함하되 정규 세력의 인구로 더하지 않는다. 창고·끝수·개인 기함의 승패 집계 포함
방식은 복원 설계다. `evidence:guess`

수도 점령 승자는 인구 90%·함정 유닛 10배·종료 시 쿠데타 없음·제국 지휘 인물 위치
조건을 모두 충족해야 결정적 승리다. 어느 하나가 확실히 거짓이면 한정적 승리,
나머지가 참이어도 필요한 정치 조건이 미확정이면 `UNRESOLVED`로 남긴다. 제국 인물
위치는 동맹의 승리에 요구하지 않는다. 수도 점령 이외 종료는 현재 정규 세력 인구를
비교해 국지적 승리를 정하며, 동수면 동맹이다. 동시 양 수도 함락의 등급은 매뉴얼
미확정으로 남긴다. `evidence:manual`(PDF 12–13쪽), `evidence:guess`(미확정 보존)

종료 시 쿠데타 조건은 반란 상태(U-10, `coup.revolting`)로 연결됐다. 2026-11-03 제국 지휘 인물 위치 조건도
연결했다(`SessionResults.imperialLeaderAtEnemyCapital`). 황제(카드 1, 반란 별칭 68)나 帝国軍最高司令官(국가 직무 2)의 보유자
중 하나라도 종료 시 동맹 수도 그리드(하이네센 2015)에 있으면 참이다. 보유자가 모두 다른 곳에 있거나 보유자가 없으면 거짓이다.
위치 기록이 없는 보유자(NPC)가 있으면 미확정으로 남겨 등급을 추측하지 않는다(`evidence:manual` W p.13, 판정 방식은 `evidence:guess`).
최종 평가·명성 보상 변환은 여전히 하지 않는다.
인구 합계는 서버에서 Long으로 보존한다. 아래 전송 단위와 등급 코드는 복원 서버의
표현 규칙이며 원작 코드/단위가 확정됐다는 뜻이 아니다.

검사: 엔진 전체 612개·저장소 전체 124개·게이트웨이 전체 204개와 배포본 빌드 통과.
새 승패/집계 6개는 90%/10배 경계·정치 조건의 거짓/미확정·동맹의 제국 조건 면제·
국지적 승리/동수·큰 수치·중립/반란 인구·생존 ID/부대 합계/창고/끝수/오프라인 기함을
대조한다. 이후 실제 파일의 두 장애 복구에서 종료 결과·두 행성/인구 20억/육전대 1의
통계 복원과 세대 재시작 시 이전 결과 해제를 보강해 관련 엔진 14개·저장소 2개를
다시 통과했다. 일반 실행 서버에는 아직 배포하지 않았다.


## 종료 통지 발행과 전용 결과 패널 연결 (2026-10-29)

작성: Peppone Choi

인증·월드 초기화를 마친 현재 세대 접속은 저장된 종료 결과가 생기면 `035a`를 한 번
받는다. 종료 후 도착한 게임 명령은 암호 스트림을 정상 소비하되 상태를 바꾸지 않는다.
시각 조회는 종료 시점으로 응답하며 다음 세대가 시작되면 이전 접속을 닫는다. 종료와
경합한 이전 비동기 조회의 실패가 결과 통지보다 먼저 접속을 닫지 않도록 처리했다.
종료 후 신규 입장·재접속 결과 조회·과거 세션 보관은 아직 연결하지 않았다.

등급의 전송 표현은 한정적 0·국지적 1·결정적 2·패배 3·미확정 255로 정했다.
종료 사유는 수도 함락 3·성계 감소 4·기간 만료 5다. 원작 숫자 의미를 복원한 것이
아니라 이 서버와 호환 모듈 사이의 명시적 표현 규칙이다. 인구는 전송 때 만 명 단위로
내림하고 패널에 단위를 표시한다. 정확한 인구 비율 판정은 변환 전 서버 값으로 한다.
미확정 정치 조건은 255이며 평가·명성은 지급하지 않고 화면에도 미확정으로 안내한다.
`evidence:guess`

호환 모듈은 원본 수신 디스패처를 통과한 종료 객체를 검증해 양 세력의 등급·행성·요새·
인구·함정/육전대 유닛·등록 인물 수를 표시하는 전용 패널을 구성한다. 기존 행성 조회의
원본 창틀/컨트롤을 재사용한 배치이며 소실된 원작 결과 화면의 정확한 재현을 뜻하지
않는다. 이전 행성/세율 조작을 숨기고 다른 월드/인물로 바뀌면 결과 상태를 해제한다.

검사: 게이트웨이 전체 206개 통과 후 보고 데이터 3개·실제 암호화 TCP 종료 2개를
추가/재실행해 통과했다. 큰 인구의 단위 변환·두 진영/합계·미확정 조건·신원/세대
불일치 거부·통지 1회·종료 후 명령 무효·종료와 비동기 조회 실패의 경합·다음 세대의
이전 접속 종료를 확인했다. 호환 모듈 빌드와 잘못된 종료 객체의 거부 검사를 통과했다.
실제 두 원본의 수도 함락부터 패널 표시까지는 아래 run-223에서 확인했다.


원본 종료 처리 후 전술/접속 플래그가 0으로 바뀌어 일반 메뉴가 조기 반환한다.
종료 결과는 이 플래그를 새 세션의 신호로 해석하지 않고, 원본 9번 창의 프레임 함수
`0054ef20`에서 `0054bb50`을 부르는 지점 `0054ef34`에 별도로 연결한다. 수신 함수는
검증된 결과만 보관하고 화면 갱신에서 패널을 만든다. 원본 위젯 조회는 범위를 검사하지
않으므로 임의 카테고리/번호를 순회하지 않는다. 기존 표의 40..61번과 닫기 버튼 26번을 재사용하고
108..110번 스크롤 컨트롤 및 120개 버튼 배열 범위를 침범하지 않는다. `evidence:client`
