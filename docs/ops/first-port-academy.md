# 첫 기항과 사관학교 연습

작성자: 최병호 · 2026-11-04

[현재 로컬 실행 방법](local-play.md)으로 로그인한다. 아래 동선은 별도 직위가 없는 동맹 생성 인물로 확인했다.
개인 기함의 함장 카드와 개인 카드로 이동·연습할 수 있다. 부대 지휘 훈련에는 해당 지휘 직무가 필요하다.

1. 수도 성계 밖이라면 **직무 권한 카드 → 함장 → 운영 → 워프 항행**으로 바라트에 돌아온다.
   이미 바라트 성계라면 이 이동은 생략한다.
2. **함장 → 운영 → 기항 → 하이네센 → 결정**을 누른다.
   MCP 160을 내고 게임 8시간을 기다린다. 현재 일반 서버의 배속 24에서는 실제 약 20분이다.
   도착하면 현재 위치가 ‘행성 하이네센’으로 바뀐다.
3. **개인 → 운영 → 원거리 이동 → 사관학교 ▶ → 경계 로비**를 고른다.
   아래 항목이 가려지면 목록 오른쪽 스크롤바를 내린다.
4. **개인 → 운영 → 근거리 이동 → 시뮬레이션실**로 들어간다.
5. **개인 → 운영 → 병기 강습**을 누른다. 열리는 창 제목은 ‘병기 연습’이다.
   지휘·기동·공격·방어 중 연습할 능력을 고르고 **연습 실행**을 누른다.

한 번에 MCP 10과 해당 능력 경험 5가 적용되며 게임 날짜 기준 하루 다섯 번 이용할 수 있다.
경험 100이 쌓여야 능력 수치가 1 오르므로, 첫 연습에서 능력 숫자가 그대로여도 경험 증가를 확인한다.
이동·연습에서 쓴 CP의 경험은 별도 주기로 정산된다. 저장된 경험과 위치는 서버 재시작 뒤에도 유지된다.

수강은 교실에서 다른 인물의 강의가 진행 중이어야 한다. 위 병기 연습은 강사가 없어도 이용할 수 있다.
제국의 오딘 동선과 일반 부대 가입까지 이번 신규 인물 시험으로 완료한 것은 아니다.
검사·실기 범위는 [CP 경험치 기록](../server/design-cp-experience.md#6-영속-월드의-신규-인물-로그인-보완-2026-11-04)을 따른다.
