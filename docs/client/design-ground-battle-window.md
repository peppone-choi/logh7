## 설계 (`evidence:guess`)

1. **서버 상태**: 육전 유닛별 공격 대상(유닛 ID→적 유닛 ID)을 저장한다. 대상이 살아 있고 같은 거점이면 그 대상을 치고, 아니면 지금처럼 순서대로 배분한다.
2. **명령**: 원본 번호 `0417`(공격 대상 지정)·`0418`(지정 해제)을 서버가 받는다. 형식은 원본 직렬화기에서 확인한 뒤 맞춘다. 지휘권·같은 거점·적 유닛 검사.
3. **상태 통지**: 지상전 거점의 양쪽 유닛(ID·세력·병종·등급·전력·대상)을 보내는 응답. 지상전 시작·교전 결과·종료 때 같은 그리드 전술 인물에게 보낸다.
4. **호환 DLL 창**: 원본 창 틀(기존 재구성 창과 같은 방식)에 왼쪽 자기 세력·오른쪽 상대를 놓는다. 장갑병은 `planetbattle` 좌·우 그림, 장갑척탄병·경장육전병은 `Thumbnail/Unit` 헬멧 병사 그림(대응은 확인 후 확정), 전력 막대·남은 수. 자기 유닛을 고르고 적을 눌러 대상 지정.
5. **열기**: 같은 그리드에서 지상전이 시작되면 자동으로 열고, 닫은 뒤에는 거점 방어력 막대(또는 정보 메뉴)로 다시 연다.

## 현황 패널 구분과 기존 지휘관 선택 (2026-11-04)

작성: Peppone Choi ([peppone-choi](https://github.com/peppone-choi))

사용자는 기존 화면의 왼쪽 글자를 창 밖으로 넘친 내용으로 오인했으나, 별도 지상전 현황 패널임을 확인했다. 따라서 넘침 수정 대신 패널 자체를 식별하고 각 수치의 뜻을 읽을 수 있게 바꿨다. 원본 창틀 복원이 아닌 사용자 승인 표시 설계다. `evidence:guess`

- 레이더 아래에 짙은 불투명 배경·청색 테두리·`지상전 현황` 제목·`자동 교전 중` 표시를 둔다. 아군은 청색, 적군은 적색 열로 나눈다.
- 교전/예비 유닛 수와 교전 병력의 남은 전력 합계를 구분한다. 각 진영 앞 5유닛에 실제 남은 전력 막대(1000 기준 백분율)와 사기를 표시한다. 예비는 아직 교전에 참가하지 않는 병력이며 합계 전력에서 제외한다.
- 아래 범례에 막대·사기·예비의 뜻, 정보 → 육전대 정보의 상세 진입 경로를 표시한다. 전투 계산·피해 주기는 변경하지 않았다. 원본 레이더 아틀라스의 흰 픽셀과 기존 스프라이트 렌더러를 재사용하며 텍스처나 입력창을 매 프레임 생성하지 않는다.
- 상세 창의 지휘관 화살표는 이미 임명된 아군 지휘관별로 담당 병력을 필터한다. 인사 임명이나 새로운 위임을 실행하지 않는다. 본인 지휘와 관찰을 표시하며 다른 지휘관/미임명 병력을 볼 때 공격 버튼을 막는다. 이름이 조회되지 않으면 ID를 표시한다.
- 서버도 같은 지휘권으로 검증한다. 명시된 부대 지휘관을 우선한다. 지휘관 없는 현지 지상부대의 원래 주둔 병력은 현재 아군 소유 거점의 수비대장/수도 방위지휘관 직위를 따른다. 다른 부대·원격/강하 병력·점령당한 거점·반란 거점의 병력을 직위만으로 가져오지 않는다. 지휘권을 잃으면 다음 명령을 거부한다. 이 수비대 연결은 기존 직위를 활용한 복원 설계다. `evidence:guess`
