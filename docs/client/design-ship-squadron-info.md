# 함정 정보·전대 정보 창 재구성 설계 (2026-10-31 승인, 1단계 구현)

작성: Peppone Choi · 2026-10-31

## 1. 배경 `evidence:client`

- **원본에 있던 메뉴:** 원본 정보 메뉴(constmsg 그룹 37)에는 다음 항목이 있다.
  - キャラクター情報·艦艇情報·旗艦情報·戦隊情報·部隊情報·陸戦隊情報·惑星要塞情報
- **창이 열리지 않는 이유:** 보유 CD의 메뉴 처리기 `0054bb50`은 분류 1(함정)·3(전대)·5(육전대)를 창을 만들지 않고 선택 해제만 한다.
- **글자는 남아 있다:** 창에 들어갈 문구는 다음 그룹에 남아 있다.

| 그룹 | 내용 |
|---|---|
| 42 | 전대 정보: 소속 진영·소속 부대·전대명·지휘관·전대 공적·기함/함정/육전대/승조원 유닛·전 함정 척수(통상/손상)·군수물자 적재량·긴급보급 대상 |
| 43 | 함정 행: 종별·척수·상태·사기치·사기 상황·태세·군수물자 적재량 |
| 44 | 육전대 행: 종별·등급·상태·사기치·사기 상황·태세·손해·스텝 |
| 47 | 소속 전대 요약: 전대명·지휘관·전대 공적·기함·함정 유닛·전 함정 척수(통상/손상)·군수물자 |
| 48 | 함종별 함정 유닛 수·척수(통상/손상) |

- **기존 재구성 방식:** 행성·부대 정보처럼 원본 창틀·컨트롤을 재사용하는 재구성 창으로 연결해 왔다. 이 창들도 원본 화면을 복원한 것이 아니라 재구성 배치다.

## 2. 제안

1. **함정 정보 (분류 1):** 선택한 일반 함정 유닛 하나의 정보를 보여 준다.
   - 그룹 43의 항목을 쓴다: 종별·척수·상태(통상/손상)·사기·태세·군수물자.
   - 데이터는 기존 `0330/0331` 유닛 조회와 전술 상태를 사용한다. 새 서버 프로토콜은 만들지 않는다.
2. **전대 정보 (분류 3):** 그룹 42·47의 항목으로 보여 준다.
   - 서버에 "전대"라는 별도 저장 단위는 없다. 그래서 전대를 다음과 같이 정의한다(`evidence:guess`): 한 부대에서 같은 전술 지휘자(`motionCommander`)가 맡은 유닛 묶음.
   - 지휘자가 없는 유닛은 부대 지휘관의 전대로 본다.
3. **육전대 정보 (분류 5):** 그룹 44의 항목으로 보여 준다.
   - 기존 부대 정보창의 병력 탭 조회(`0331` 모드 2)를 재사용한다.
4. **공통 사항**
   - 창은 기존 `planet_window`·`outfit_information`과 같은 방식(원본 창틀 재사용)으로 호환 DLL에 둔다.
   - 값이 없거나 권한이 없으면 0을 채우지 않고 "조회 불가"로 표시한다.
   - 적 진영 유닛은 색적 범위 안에 있을 때만 기본 항목을 보여 준다.

## 3. 결정이 필요한 점

1. 세 창을 모두 재구성할지, 함정·육전대만 먼저 할지
2. 전대를 "같은 전술 지휘자 묶음"으로 정의하는 것에 동의하는지
3. 적 유닛 정보 공개 범위(색적 범위 안의 기본 항목만)

## 4. 1단계 구현 (2026-10-31)

- **승인:** 사용자가 제안대로 승인했다.
- **연결 방식:** 정보 메뉴의 함정(1)·전대(3)·육전대(5)를 고르면 본인 부대를 기존 재구성 부대 정보창(창 13, 원본 탭 틀)으로 연다.
  - 함선 편성 탭이 함정 정보, 병력 편성 탭이 육전대 정보, 부대 개요가 전대 요약 역할을 한다.
- **본인 부대 찾기**
  - 인물 `+0x324`를 먼저 본다. 전략 기함 부두에서는 0이었다(`evidence:client`, 원본 덤프).
  - 0이면 보유한 부대 지휘 직무 카드(`+0x270` 개수, `+0x274` 종류, `+0x278` 대상)의 대상을 부대 ID로 쓴다.
  - 종류·번호는 칸 부대 목록 캐시(`+0x811fc`)에서 찾는다.
- **탭 갱신:** 현재 거점(`+0x358`)이 있으면 주둔 부대 경로(`openStationedOutfit`)로 열고, 매 프레임 탭 컨트롤러를 돌린다.
- **원본 확인**(`work/info-window-20261031`): 동맹 multi0을 시험 준비로 하이네센 기함 부두에 두었다.
  - `함정 정보`와 `육전대 정보`가 제1함대 창을 열었다.
  - 함선 편성 탭으로 전환하면 함종별 유닛·척수가 표시됐다.
- **남은 것**
- **재열기 수정**(`run-07`~`run-11`)
  - 원인 1: `0054bb50`은 시작할 때 창 13을 잡아 두었다가 선택 처리 뒤 숨긴다. 그래서 창이 이미 있을 때는 연 직후 다시 숨겨졌다. 창 열기를 다음 프레임으로 미뤘다.
  - 원인 2: 부대 응답 대기열은 맨 앞 요청과만 짝을 지었다. 닫힌 창의 답 없는 창고 요청이 맨 앞에 남으면, 다음 편성 응답이 매칭되지 않고 시간 초과("응답을 받지 못했습니다")가 됐다. 응답과 맞는 요청까지 앞쪽의 오래된 요청을 함께 버리도록 고치고 guard 검사를 추가했다.
  - 원본에서 육전대→전대→함정 정보를 열고 닫기를 반복해 세 번 모두 편성이 표시됨을 확인했다.
  - 전대 고유 묶음(같은 전술 지휘자)과 선택 유닛 단위 정보, 적 유닛의 색적 범위 기본 항목은 2단계로 남는다.
  - 우주(거점 없음)에서 여는 경로의 탭 갱신은 미확인이다.
