# 인사·작전계획·병참

## 1. 평가 포인트와 명성 포인트 `evidence:manual` (W p.34)

| 포인트 | 범위 | 증가 | 감소 |
|---|---|---|---|
| 評価ポイント | 세션 내 | ① 전술에서 적 유닛 격파·적 행성/요새 점령 ② 소속 세력 승리 시 **최종 계급**에 따라 지급(생존 필요) ③ 준장 이상은 사망 시 계급에 따른 고정값(승패 무관) | 경비함 구매·기함 구매에 사용(update03·05) |
| 名声ポイント | 세션을 넘어 영속 | 세션 종료 시 평가 포인트를 환산해 가산 | **오리지널 캐릭터 선택 시 소비** |

수치(계급별 지급액, 환산율, 원작 캐릭터별 소비량)는 매뉴얼에 없음 → `evidence:guess`.

## 2. 공적과 계급 `evidence:manual` (W p.35)

- 같은 계급의 캐릭터는 공적 포인트 내림차순으로 줄 세운다 = **階級ラダー**. 군인용·정치가용 래더가 따로 있다.
- 래더 순위만으로 승진하지 않는다. **인사권 직책이 커맨드를 실행해야** 승진. 예외: **대령 이하는 매월 1일 각 래더 1위가 자동 승진**(W p.35는 "현실 시간 매월 1일", W p.36은 "게임 내 30일마다 점검"이라 서로 다르게 적혀 있다 → 구현 시 결정 필요, 미결 Q-M1).
- 래더 순위 규칙(점수 변동 시 재계산):
  1. 공적 포인트 많은 순
  2. 작위 높은 순(제국만)
  3. 보유 최고 훈장 순위 — **서훈은 현재 미구현**이라고 명기 → U-05
  4. 영향력 높은 순 (「影響力」 수치의 정의는 이 매뉴얼에 없음)
  5. 전 능력치 합계
- 계급 정원:

| 계급 | 제국 | 동맹 |
|---|---|---|
| 元帥 | 5 | 5 |
| 上級大将 | 5 | (없음) |
| 大将 | 10 | 10 |
| 中将 | 20 | 20 |
| 少将 | 40 | 40 |
| 准将 | 80 | 80 |
| 大佐 이하 | 제한 없음 | 제한 없음 |

## 3. 승진·강등 `evidence:manual` (W p.36)

인사권자:

| 대상 계급 | 제국 | 동맹 |
|---|---|---|
| 元帥 | 皇帝 | (명시 없음 — 표가 비어 있음) |
| 上級大将~准将 | 軍務尚書 | 国防委員長 |
| 大佐 이하 | 軍務省人事局長 | 国防委員会人事局長 |

- 인사도 커맨드의 하나이므로, 제안으로 자기 계급 변경을 청원할 수 있다.
- **승진**: 한 계급 위 래더의 **최하위**로 편입, 공적 **0**으로 초기화, 「個人」「艦長」「封土」 외 모든 카드 상실. 대령 이하 자동 승진자는 해당 래더 평균 공적을 받는다.
- **강등(降等)**: 한 계급 아래 래더 최하위, 공적 **100**으로, 「個人」「艦長」「封土」 외 모든 카드 상실. 대령 이하는 게임 30일마다 강등 조건 점검 후 자동 강등(조건 수치는 매뉴얼에 없음).
- 「封土」 카드가 존재함을 알 수 있다(봉토 = 귀족 영지 관련으로 추정 `evidence:guess`).

## 4. 기함 변경 `evidence:manual`

- 매뉴얼(2004-10): 기함 종류는 캐릭터 작성 시 계급으로 정해지고, 계급이 바뀌면 새 계급에 맞는 기함으로 자동 변경. "**잠정 사양**"으로 명기. (W p.37)
- 패치(REVIEW 05, 2005-04 캡처): 「旗艦購入」 커맨드 도입. 수도 행성의 「旗艦工廠」 스폿에서만, 평가 포인트로 구매, 계급 제한, 원작 특수 기함(브륀힐트·휴베리온 등)도 대상. **격침되면 계급과 무관하게 구축함으로 복귀.** (update05)
- 같은 패치: 우주 전술에서 철수 시, 철수 커맨드를 실행한 위치 방향의 **인접 그리드로 철수**하도록 변경(이전: 자기 진영 쪽으로 워프). 회랑 봉쇄 돌파가 가능해짐. (update05)

### 기함 구매·합의 교환의 현재 연결 (2026-10-29)

작성: 최병호

`evidence:manual` 구매 장소·평가 포인트·계급 제한은 `wayback/update05-20050418003249.utf8.txt`의 패치 설명을 따른다. `evidence:client` 보유 CD의 `constmsg.dat` 그룹 73/74에도 기함공창 시설 23과 접수 스폿 21이 있다. 현재 서버가 생성하는 수도의 해당 장소에서 개인 카드 0의 구매창을 열도록 연결했다. 원본 구매 opcode와 후속 패치 UI를 복원한 것은 아니며, 기존 `1200 / search 7f00` 복원 확장을 사용한다.

`evidence:guess` 현재 구매 목록은 서버에 기함 성능·모델이 연결된 아래 네 종류만이다. 원작 함종별 가격과 계급표를 아직 확보하지 못해 가격·계급 문턱은 대체 정책이다. 구매는 PCP 80과 평가 포인트를 같은 월드 저장에서 차감하며, PCP가 부족하면 MCP 160 전액 대용이다. 구매한 기함은 손상 없는 상태로 바뀌고 개인 군수물자는 보존한다. 같은 종류 재구매, 부상·전술·보급 작업 중 구매, 잘못된 장소, 잔액·계급 부족은 거부한다.

| 종류 | 제국/동맹 kind | 평가 포인트 | 계급 문턱 |
|---|---|---:|---|
| 구축함 | 3 / 93 | 50 | 이등병 이상 군인 |
| 순항함 | 2 / 90 | 200 | 소령 이상 |
| 표준전함 | 0 / 89 | 500 | 준장 이상 |
| 양륙함 | 4 / 94 | 150 | 소령 이상 |

`evidence:guess` 사용자가 요청한 양도는 **양측 합의에 따른 기함 교환**으로 연결했다. 원작에 같은 교환 명령이 있었다는 근거는 없다. 한 사람이 제안하면 상대가 자신의 창에서 수락해야 하며, 양측이 같은 진영·수도 기함공창 접수 스폿에 있어야 한다. 현재 기함의 손상·실드 상태까지 서로 교환하고 각자의 군수물자는 보존한다. 제안·취소는 무료, 수락자가 PCP 80을 낸다. 제안은 게임 24시간 유지되고 어느 쪽이든 취소할 수 있다. 로그아웃한 상대에게도 제안은 저장되지만, 그 상대의 접속·수락 없이 기함을 바꾸지 않는다. 수락 때 현재 장소·직업·계급·기함 종류·부상·작업 상태를 다시 검사한다.

교환 제안은 `STOCK-31`의 별도 `M` 행에 저장한다. `S`(전략)와 `C`(전술) 문법은 바꾸지 않았다. 기함 두 개와 수락자의 CP, 제안 소멸은 하나의 월드 슬롯 전환으로 확정한다. 특수 기함·고속전함 등 나머지 함종과 평가 포인트 획득 루프의 전투 연계는 남아 있다.

실제 두 클라이언트 run-267에서 함대사령관 카드의 완전수리로 MCP `1000→840`, 잔존 유닛 손상 `50/25→0/0`, 부대 군수 `1000→0`, 두 기함 HP `55/90→100/100`을 확인했다. 척수 `200/150/0`은 보존돼 파괴된 유닛을 부활시키지 않았다. 개인 카드에서 구축함 구매로 평가 `1000→950`, PCP `1000→920`, 동맹 kind `89→93`이 저장됐다. 제안 때 두 기함과 CP는 그대로였고 상대 창의 수락 뒤 `93/90→90/93`, 수락자 PCP `1000→920`, 제안 소멸을 확인했다. 원본 한 개 재접속과 run-268 서버/두 원본 재시작 뒤에도 보존됐으며 완전수리 재확정은 무변경·무과금이었다. 교환 설명의 창 밖 넘침을 줄이고 run-268에서 표시를 확인했다. 장소·직위·손상·평가는 QA 사본에 준비했으므로 생성부터 해당 장소에 이르는 전체 플레이 검증은 아니다.

통합 서버 검사 1,202건 중 실패 0·건너뜀 5, 앱 배포본·x86 DLL 경고 오류 처리 및 guard 빌드는 통과했다. 실행·상태·화면은 `work/native-multiplayer-20261028/market267-*`, `market268-*`, `strategy266-regression.log`, 작업 워크트리의 `work/native-multiplayer-20261028/run-267`, `run-268`에 남겼다. 전체 함종·권한·실패 조건의 실제 클라이언트 검증은 남는다.

## 5. 임명과 파면 `evidence:manual` (W p.37)

- 모든 직책의 인사권은 **상위 직책**에 있다. 계급상 최상위 직책을 제외한 전 직책이 대상이며 제한이 없어 **원작 캐릭터도 초기 직무에서 파면될 수 있다.**
- 직책마다 **임명 가능한 계급 범위**가 있다. 범위 밖이면 임명 불가. 범위 안이라도 **대상자가 임명자와 같거나 높은 계급이면 불가.**
- 인사 조직 상세는 부록 조직표 → [06-organization-tables](06-organization-tables.md).

## 6. 작전계획(作戦計画) `evidence:manual` (W p.38–40)

- 목적: 진영의 전략 목표 공표. 계획에 따른 행동은 통상 격파 공적과 별도로 **보너스 포인트.**
- 설정 항목:
  - 作戦目的: **占領**(적 성계 점령) / **防衛**(자기 성계 일정 기간 유지) / **掃討**(특정 그리드 적 격파; 독행함 대상일 때만 제시 가능)
  - 目標星系: 점령 = 계획 시점에 타 진영 행성/요새만 있는 성계, 방위 = 자기 진영 행성/요새가 1개 이상 있는 성계, 소탕 = 모든 성계
  - 参加艦艇ユニット数: 부대 카테고리별 제한 → 사실상 참여 부대 수
  - 発動予定時期: **이에 따라 작전계획 커맨드의 CP 비용이 달라진다**
- 제한: 목표 조건을 잃으면 즉시 자동 철회·소멸 / 한 카드에서 목표 성계 중복 불가 / 모든 작전의 참가 유닛 합계 ≤ 세력의 유효 함정 유닛 총수 / 유닛 부족으로 기존 계획 지속이 불가하면 해소 전까지 신규 계획 불가
- **発令**: 계획을 세우는 직책과 발령하는 직책은 **다른 부서.** 발령 = 계획 유닛 수에 맞춰 실제 참여 부대 지정. 발동 시기 전에는 부대 할당 불가.
- 개시: 발령된 부대(또는 독행함) 일부가 목표 성계에 도달한 시점.
- 기간: 발령 시점부터 **게임 30일** 후 종료. 입안자가 【作戦撤回】하면 즉시 종료.
- 결과(게임 30일 후 판정):

| 작전 | 전면 성공(보너스 100%) | 부분 성공(약 50%) |
|---|---|---|
| 占領 | 목표 성계의 모든 행성/요새 지배 | 1개 이상 지배 |
| 防衛 | 모든 행성/요새를 빼앗기지 않음 | 1개 이상 빼앗김 |
| 掃討 | 지정 성계 **400광년 이내**에서 적 함선 1척 격침마다 보너스 | — |

- 보너스 기준값, 발동 시기별 CP 공식은 매뉴얼에 없음 → `evidence:guess`.

## 7. 병참(兵站) `evidence:manual` (W p.41–45)

### 7.1 페잔
- 페잔 자치령은 중립. 중립 침범·무력 점령 시 특별 페널티 — **페잔 점령은 현재 미구현.** (W p.41) → U-07
- CD판에는 「フェザーン」 절(CD p.38)이 따로 있었으나 웹판 목차에서 빠졌다(개발방침 변경 공지에서 페잔 외교·첩보 기능 연기/재검토 발표). → [00-editions](00-editions.md)

### 7.2 생산
- 함정 유닛: 행성/요새의 **造兵工廠**에서 건조. 공창 없는 곳은 생산 안 함.
- 병사(승조원·육전병): 거주 인구에서 **모병.** 인구 있는 행성이면 어디서나 가능. 모병하면 그 행성 징세 수입 감소.
- 숙련도 4단계: **エリート / ベテラン / ノーマル / グリーン.** 생산 결과는 항상 グリーン. 훈련·실전으로 변화.
- **현 버전은 자동 생산**이며 설정을 바꿀 직책이 없다. 지배권이 바뀌지 않는 한 계속 생산. 자동 생산은 세수에 영향 없음. 품목은 웹판 p.76–78 자동 생산표에 수록되어 있다([08 검증](08-organization-units-data.md)). 군수물자 1G일 생산은 [09 P11](09-patch-history.md)에서 확인되며, 함선·병원 품목별 생산량·주기는 별도 확인이 필요하다. `evidence:manual`
- 개발방침 공지: "기함 구매 다음" 단계로 **생산계 커맨드(시설·함선 건조)** 추가 예정 → U-08

### 7.3 창고
- **惑星倉庫**: 행성/요새 보유. 중앙정부 관할. 생산물은 완성 즉시 자동 입고.
- **部隊倉庫**: 부대 전용. 다른 부대는 못 건드림. 단 **순찰대·지상부대는 부대별 구분 없이 일괄 공용 창고.** 재편성·보충 시 끝수(端数) 유닛은 자동 합산.

|---|---|---|---|---|
| 統帥本部作戦一課長(제국) | ○ | × | × | × |
| 統帥本部作戦二課長(제국) | × | ○ | ○ | ○ |
| 統合作戦本部第三次長(동맹) | ○ | ○ | ○ | ○ |

- 제한: 어느 부대든 【再編成】【補充】 실행 중에는 할당 불가, 할당 중에는 재편성/보충/반출입 불가(상호 배제 락).

공통 코드 근거: `BootstrapMessages.OfficeCard`, `GameAdministration.offices`, `NationalOffice`, `FleetOffice`, `BaseOfficePolicy`, `GarrisonAppointment`, `CapitalAppointmentPolicy`, `OfficeDismissal`, `OfficeResignation`, `FilePlanetStockStore`. 임명·서작·봉토 수여는 개인/함장 외 카드 14장 한도를 검사하고, 같은 종류의 복수 직위는 저장된 거점·부대 좌석으로 구별한다. 다만 원본 해임/사임 요청은 좌석을 보내지 않으므로 동일 종류를 중복 보유하면 임의 선택 없이 AMBIGUOUS로 거부하며, 이를 직접 선택해 해임/사임하는 조작 경로는 남아 있다. 승진/강등의 직위 회수도 `PersonnelActions`에서 연결한다. 이 서버 판정과 원본 목록의 실제 선택·해임·사임·재접속을 모두 확인한 상태는 구분한다. 착임/퇴거 전체 규칙·초기 인물 임명과 직위별 원본 검증은 남는다. 전략 커맨드 81개 자체의 연결은 [커맨드 표의 현재 서버 열](07-command-table.md)을 따른다.
