# 메일·메신저·채팅

## 1. 메일 `evidence:manual` (W p.16)

- 주소는 두 종류: **개인 고유 주소** + **직무권한 카드(職務権限カード)에 딸린 주소**. 카드를 여러 장 가지면 주소도 그만큼 늘어난다(예: 참모장 카드 + 함대사령관 카드 + 개인 = 3개).
- 전략 게임 중이면 어디서든 수신, **전술 게임 중에는 수신 불가.**
- 개인 주소는 채팅의 「名刺交換」으로만 얻는다(교환 여부는 플레이어 선택).
- 주소록 최대 **100개**, 임의 삭제 가능. 주소록에 없는 주소에서 온 메일에도 답장 가능.
- **망명**으로 소속이 바뀌면 주소록 전체 삭제.
- 수신함 최대 **120통**. 가득 차면 오래된 메일을 지우기 전까지 새 메일을 받지 못한다.

서버 메모 `evidence:guess`: 카드 주소는 카드(직책)에 귀속되므로 인사로 카드가 넘어가면 주소·수신함 귀속을 어떻게 할지 결정 필요(매뉴얼에 없음). 작전 "제안 메일"(ns-update의 提案メール処理)과 연결된다.

## 2. 메신저 `evidence:manual` (W p.17)

- **1:1 연결** 상태를 만든 두 사람 사이의 대화. 다른 사람과 대화하려면 기존 연결을 끊고 새로 연결.
- 온라인 목록에서 이름을 더블클릭 → 호출. 호출은 한 번에 1명, 호출 중 새 호출 시 이전 호출 취소, 연결 중에 호출하면 기존 연결 끊김.
- 받는 쪽은 목록의 호출자 이름 더블클릭으로 연결. 여러 호출 중 하나와 연결하면 나머지는 취소.

## 3. 채팅

### 3.1 매뉴얼(2004-10) 기준 `evidence:manual` (W p.17–18)

- 같은 시점에 **같은 스폿(スポット)** 에 있어야 채팅 가능. 스폿 = 캐릭터 소재 구획(자택·회의실·술집 등).
- 같은 부대원끼리는 스폿이 달라도 **같은 그리드**에 있으면 채팅 가능.
- 전술 게임 중에는 같은 그리드의 자기 진영 전원에게 채팅 가능.
- 채팅 커맨드: 「名刺交換」(개인 메일 주소 전달), 「キャラクター情報取得」(상대 정보 열람).

### 3.2 채널 채팅 (2004-12 도입 예고 → REVIEW 02에서 도입 소개) `evidence:manual`

- 개발방침 변경 공지(ns-update, 2004-10)에서 "12월 도입 예정: 채팅 기능 강화(전체 채팅)"로 예고.
- update02(REVIEW 02)에서 **8개 채널**을 소개. 사용 가능 채널은 직무에 따라 달라지고, 보낼 때는 눌려 있는 채널 버튼으로 전송, 표시란은 채널별 색 구분.

| 채널(원어) | 대상 |
|---|---|
| 部隊所属 | 자기 진영에서 함대·순찰대 등 어떤 부대에든 소속된 플레이어 |
| 未所属 | 어느 부대에도 속하지 않은 플레이어(경비대 편성자 포함) |
| 自部隊 | 자기 부대 안 |
| 軍政 | 중앙정부·행성 지사/총독·요새사령관 등 |
| スポット | 기존 채팅과 같은 스폿 |
| 布告 | 정부 수뇌부(황제·의장·군무상서·국방위원장 등) |
| 同陣営 | 전술 중에만, 같은 스폿의 자기 진영 전원 |
| 両陣営 | 전술 중에만, 같은 스폿의 제국·동맹 전원 |

布告 참여 직책(update02): 동맹 — 의장/국방위원장/통합작전본부장/우주함대사령장관/후방근무본부장, 제국 — 황제/군무상서/통수본부총장/우주함대사령장관/제국재상. 軍政 참여는 제국·동맹 각 중앙 기관·요새방위사령부·행성정청·행성방위사령부 소속 직무 전체.

클라이언트 대응 `evidence:guess`: 설치본(버전 131, 2004-04 빌드)이 채널 UI를 갖고 있는지는 불확실하다. 채널 기능은 2004-12 이후 패치로 들어왔을 가능성이 높아, 보유 클라이언트에서 쓰려면 클라이언트 쪽 흔적 확인이 먼저다(트랙 B, 미구현 후보 U-06).
