## 1. 조직 요약 `evidence:manual`

### 제국 (58개 직책)
- 皇宮: 皇帝 — 帝国軍最高司令官·幕僚総監(대본영)·帝国宰相. 親政이면 황제가 최고사령관·재상 겸임.
- 内閣(재상 임명): 国務尚書(**행성총독 임면권**), 内務尚書(**대령 이하 군인 체포·처단**), 財務尚書(**과세율**), 司法尚書(**정치가 체포·처단**), 宮内·典礼·科学尚書(명목직), 内閣書記官長.
- 軍務省: 軍務尚書(황제 직임, **군 인사**) — 次官, 人事局長(대령 이하 인사), 調査局長(統合偵察局·첩보), 参事官×10.
- 統帥本部: 総長(황제 직임, 편성·작전계획) — 次長, 作戦一課(함대), 二課(수송함대·순찰대·지상부대), 三課(독행함), 監察官×10.
- 宇宙艦隊司令部: 司令長官(최고사령관 임명) — 副司令長官, 総参謀長(독행함 운용), 参謀×10.
- 憲兵本部(원수 이외 군인 체포), 装甲擲弾兵総監部(육전), 科学技術総監部, 士官学校, 首都(帝都防衛司令官·近衛兵総監), 統合偵察局(諜報官×50).
- 부대: 艦隊(최대 18,000척), 輸送艦隊, 巡察隊(최대 900척), 地上部隊, 要塞, 행성(惑星総督·惑星守備隊指揮官).

### 동맹 (63개 직책)
- 最高評議会: 議長 — 副議長·各委員長(国務·国防·財政·法秩序·天然資源·人的資源·経済開発·地域社会開発·情報交通)·書記. 전원 정치가.
- 統合作戦本部(本部長=국방위원장 임명; 第一~第三次長, 参事官×10, 陸戦総監部長), 後方勤務本部(本部長·次長·参事官, 科学技術本部長, 憲兵司令官), 国防委員会(査閲·戦略·人事·防衛·情報·通信·装備·施設部長 + 経理·教育·衛生部長은 정치가), 宇宙艦隊司令部, 士官学校, 部隊(艦隊·輸送艦隊[최대 6,900척]·巡察隊·地上部隊·要塞), 행성(知事·惑星守備隊指揮官), 首都(首都司政官·首都防衛指揮官), 戦略作戦局(諜報官×50).

### 인사 체인 요점
- 임명 불가 조건: 직책별 계급 범위 밖, 또는 대상자가 임명자와 **같거나 높은 계급**(부록 머리말 주석).
- 원작 캐릭터도 파면 대상(W p.37). 초기 보유자는 `initial-card-holders.csv`(예: 제국 皇帝 = フリードリヒⅣ世, 帝国宰相·国務尚書 = リヒテンラーデ, 軍務尚書 = エーレンベルグ元帥, 宇宙艦隊司令長官 = G.ミュッケンベルガー元帥, 第2艦隊 = ローエングラム中将 등).
- 세션 시작 시점은 원작 초반(라인하르트 중장, 키르히아이스 소령=사령관 부관)으로, **우주력 796년 전후**로 보인다 `evidence:guess`. 종료 기한 801-07-27(W p.12).

## 2. 초기 배치 `evidence:manual` (W p.75–78)

- 함대 번호별 초기 성계·행성(예: 제국 第1艦隊 ヴァルハラ/オーディン, 동맹 第1艦隊 バーラト/ハイネセン), 순찰대 번호별 배치, 행성별 초기 함정·승조원·육전병 유닛 종류.
- 성계·행성 이름 목록은 전략 지도 시드의 1차 자료다. 그리드 좌표는 매뉴얼에 없으므로 **클라이언트 맵 데이터**(트랙 B)에서 얻어야 한다.

- 동맹 함종: 標準戦艦(787年型), 巡航艦(795年型), 打撃巡航艦(794年型), 駆逐艦(796年型), 戦闘艇母艦(796年型), 工作艦(793年型), 輸送艦(792年型), 兵員輸送艦(788年型), 揚陸艦(795年型), 民間船.
