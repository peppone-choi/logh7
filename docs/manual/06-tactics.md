# 전술 게임

## 1. 시작·종료 `evidence:manual` (W p.46)

- 시작: 한 그리드에 아군 유닛과 적 유닛이 함께 존재.
- 종료: 그 그리드에 적 유닛이 하나도 없음. 행성/요새가 있는 그리드는 추가로 **그리드 안의 모든 행성/요새를 점령**해야 종료.
- 전술 중 적 격파·점령 → 공적 포인트. **게임 30일마다 집계해 공적 랭킹으로 평가 포인트 지급.**

## 2. 유닛 분류 `evidence:manual` (W p.46)

| 분류 | 단위 | 종류 |
|---|---|---|
| 陸戦隊ユニット | — | 装甲兵 · 装甲擲弾兵 · 軽装陸戦兵 |
| 旗艦ユニット | 1척 | 고유명 특수 기함(ヴィルヘルミナ, パトロクロス 등) / 일반 함정에서 뽑은 범용 기함 |
| 艦艇ユニット | **1유닛 = 300척** | 戦艦 · 高速戦艦(제국) · 巡航艦 · 打撃巡航艦(동맹) · 駆逐艦 · 戦闘艇母艦 · 雷撃艇母艦(제국) · 揚陸艦 · 輸送艦 · 兵員輸送艦 · 工作艦 — 11종, 각 서브타입 「戦艦Ⅰ型」 식 |

함종별 수치는 부록(W p.79–100) → [08-unit-data](08-unit-data.md).

## 3. 지휘권 `evidence:manual` (W p.47)

- 전술 진입 시 같은 부대의 함정·육전대 유닛 지휘권이 자동 배정. 우선순위: ① 현재 온라인 ② 계급 높은 순 ③ 평가 포인트 많은 순 ④ 공적 포인트 많은 순.
- 개시 후 변경 가능 조건: 대상 유닛이 다른 기함의 커맨드 레인지 서클 밖에 있고, 어떤 커맨드도 실행 중이 아닌 완전 정지 상태.

## 4. 커맨드 레인지 서클(CRC) `evidence:manual` (W p.47–48, p.53)

- 전대(戦隊)에 대한 커맨드는 기함 유닛(함대/수송함대/순찰대/독행함/지상부대) 또는 방위사령부(수비대)가 기점. 기함 자체·캐릭터 개인 커맨드는 CRC 영향 없음.
- CRC 안의 **같은 전대** 유닛에만 발령 가능. 사기 저하로 **혼란한 유닛**에는 효과 없음.
- 반경은 시간에 따라 기함별 상한까지 커지고, **커맨드 1회 발령마다 0으로 줄어든다.**
- 최대값 = 기함 능력, 확대율 = 캐릭터 「指揮」. 독행함은 CRC 개념 없음.
- 모든 커맨드는 입력 후 처리 개시까지 **0~20초**. 남은 시간 바 표시.
- CRC 최대 범위 밖 유닛은 받은 커맨드를 끝까지 수행하고, 없으면 그 자리에 머문다.

## 5. 색적 `evidence:manual` (W p.49)

- 항상 자동. 범위 = 유닛 성능 + 조함 패널 [SENSOR] 배분. 정밀도 = 거리 + 대상 유닛 종류. **정지 시 자동 집중 색적**으로 정밀도 상승.
- 색적 회피(索敵回避) = 유닛 고유 하드웨어 능력. **정지 시 자동 전자전**으로 상승.
- 한 전술 안에서 색적 정보는 **아군 전원 공유.** 같은 적에 대해 성공·실패가 동시에 나면 성공으로 처리.

## 6. 조함 패널(操艦パネル) — 기함 에너지 배분 `evidence:manual` (W p.24, st-tactics2)

| 항목 | 효과 |
|---|---|
| BEAM | 빔 병기 출력(공격력·충전 속도) |
| GUN | 건 병기 출력 |
| SHIELD | 전후좌우 4방향 실드 회복력 |
| ENGINE | 전술 이동 속도 |
| WARP | 철수 준비. **최대치를 넣어야** 전술 맵 원 밖에서 철수 가능 |
| SENSOR | 색적 범위 |

총 에너지는 기함 함종에 따라 다르며 대형함일수록 많다(st-tactics2).

## 7. 함대전 `evidence:manual` (W p.50)

- 사선 판정: 빔/건/미사일은 사선에 아군 함정(이동 요새 포함)이나 사선 장애 지형이 있으면 발사 불가.
- 빔/건: 중·근거리. 건 공격은 함정의 「ガン消費」만큼 군수물자 소비.
- 미사일: 원거리. 「ミサイル消費」만큼 군수물자 소비.
- 전투정: 공격력은 작지만 대상 함정의 이동 속도 저하, 자기를 공격 중인 적 전투정 격퇴. 출격 시 일률 10 군수물자.
- 매뉴얼 표기상 **"공격에 의한 물자 감소"와 "전투정"은 현재 미구현** → 개발방침 공지(2004-10)에서 **10월 도입 예정**으로 발표(空戦・物資消費). 보유 클라이언트(2004-04 빌드)에 구현이 있는지는 트랙 B 확인 필요 → U-03, U-04
- 요새포: 지형 장애만 없으면 발사, **사선상의 모든 유닛에 자동 명중(아군 포함).** 방향 지정 후 충전 시작, 충전 완료 시 자동 발사.

## 8. 지상전 `evidence:manual` (W p.51–52)

- 함정이 육전대를 싣고 있어야 발생. 행성/요새의 **地上戦ボックス**에서 진행. 박스 수용 **진영당 30유닛**(그리드 300 제한에 포함). 방어측 배치율 바: 30유닛 = 100%.
- 절차: ① 육전대 탑재 함정을 행성/요새에 **碇泊** ② 【陸戦隊出撃】으로 강하 ③ 적 육전대가 있으면 자동 지상전.
- 참가 가능 유닛: 일반 행성 = 3종 전부 / 가스 행성 등 특수 = 装甲擲弾兵·軽装陸戦兵 / 요새 = 装甲擲弾兵·軽装陸戦兵. **행성 타입은 현재 미구현** → U-09
- 점령 처리(적 육전대 완전 배제 시 자동):
  - 패배 진영: 그 행성/요새 고유 카드(행성총독·수비대지휘관·封土 카드 등) **즉시 상실.** 점령 진영은 해당 카드를 얻되 **별도 임명**이 있어야 유효.
  - 패배 진영 수비대 육전대 즉시 전멸 처리.
  - 그곳의 패배 진영 캐릭터 전원 즉시 기함과 함께 출격해 碇泊 상태로.
  - 창고 군수물자는 점령 진영 소유. **건조 중·계류 중·창고 보관 함정은 전부 파괴.**
  - 시설은 점령 진영 소유. **제국이 점령한 곳은 자동으로 帝室 직할령.**

## 9. 손해와 전사 `evidence:manual` (W p.52)

- 기함: 1척, 통상/손해 상태. 손해는 공작함 수리까지 지속, 격파되면 그 전술에서 제외.
- 함정 유닛: 300척 각각 통상/손해, 격파는 1척씩 감소.
- 탑재물(자원·무기·군수물자)은 잔존 척수에 비례해 감소. 탑재 육전대는 다른 함으로 자동 이동, 단 잔존 척수가 일정 수 이하가 되면 전멸.
- 전사: 원칙적으로 플레이어 선택. 보통은 기함이 격파돼도 죽지 않고 「負傷」 처리 후 설정한 **帰還惑星**으로 즉시 워프(시스템 설정 → 게임 설정 → 귀환 행성 설정). **전사는 현재 미구현** → U-11

## 11. 최고사령관과 임무 (패치, REVIEW 04) `evidence:manual` (update04)

- 전술 그리드의 자기 진영에서 **가장 계급 높은 캐릭터가 자동으로 최고사령관**(이름 앞 ★). 동계급이면 공적 포인트 큰 쪽.
- 최고사령관 전용 임무 커맨드로 진영 전원에게 지시 창을 띄우고, 따르면 공적 보너스.
- **오프라인이면서 AI를 ON으로 둔 캐릭터**에게도 임무를 줄 수 있고, AI가 임무에 따라 자동 행동.

| 임무 | 조건·보상 |
|---|---|
| 防衛 | 자기 행성/요새 선택. 다른 임무가 오거나 전술이 끝날 때까지 지배 유지 = 성공. 수비대 기본 임무. 성공 중 **24G분마다** 일정 포인트 |
| 占領 | 타 세력 행성/요새 선택. 점령 시 일정 공적 |
| 迎撃 | 타 세력 전대 선택. 지정 유닛 격파 공적 **3배** |
| 遊撃 | 임무 없음. 수비대 외 기본 |
| 偵察 | 24G분마다 점검, 목표 유닛 **1200만 km** 이내면 일정 공적 |
| 撤退 | 그리드 이탈. **4G시간** 이내 철수 시 일정 공적 |

## 13. 서버 구현 메모 `evidence:guess`

- 전술은 그리드 단위 실시간 시뮬레이션 인스턴스. 원작 서버는 "모든 커맨드는 서버가 처리"(W p.10)이므로 이동·사선·명중·색적 판정을 서버가 계산했을 가능성이 높다. 다만 클라이언트가 어느 수준까지 로컬 시뮬레이션을 하는지는 프로토콜 분석으로 확정해야 한다(트랙 B).
- 필요한 서버 상태: 유닛 위치·방향·속도, CRC 반경, 에너지 배분, 사기, 실드 4방향, 색적 공유 집합, 커맨드 대기 큐(0~20초 + 커맨드별 대기/소요).
