# 전략 게임 핵심

## 1. 전략 화면 구성 (클라이언트 측) `evidence:manual` (W p.19–21)

| 요소 | 내용 | 서버 관련성 |
|---|---|---|
| メインビュー | 은하 일부 확대. 사각 칸 = **그리드**(한 변 100광년). 전략 이동은 전부 그리드 단위. 전술 중 각 직무 커맨드도 여기서 입력 | 그리드 좌표계 |
| 銀河マップ | 은하 전체도 + 표시 범위 커서 | 전체 맵 데이터 |
| 情報ビュー | 자기 캐릭터 간이 정보 | 캐릭터 상태 동기화 |
| 職務権限カード 탭 | 보유 카드 목록 → 카드 선택 → 커맨드 실행. 제안/명령도 여기서 | 커맨드 요청 진입점 |
| 同スポットキャラクター 탭 | 같은 스폿의 모든 캐릭터 | 스폿 인원 목록 동기화 |
| 시스템 아이콘 | 메신저 / 정보(7종: キャラクター·旗艦·戦隊·部隊·惑星要塞·国家·地形 정보) / 메일 / 시스템(종료·사운드·게임 설정) | 정보 창 7종 = 조회 요청 7종 후보 `evidence:guess` |
| チャットウィンドウ | 상단 시스템 메시지, 하단 채팅 | 시스템 메시지 채널 |

전술 화면·조함 패널은 [06-tactics](06-tactics.md) 참고.

## 2. 직무권한 카드(職務権限カード) `evidence:manual` (W p.27, p.32)

- **모든 커맨드는 카드를 통해 실행한다.** 카드 = 직책에 딸린 실행 가능 커맨드 묶음.
- 모든 캐릭터는 최소 「個人」「艦長」 카드를 가진다(이동 등 기본 커맨드).
- 겸임 가능 → 여러 장 보유. **1인당 최대 16장.**
- 직책별 초기 카드 보유 정보는 부록 표(W p.60–61 제국, p.66–67 동맹)에 있다 → [05-organization](05-organization.md).

## 3. 커맨드 포인트(CP) `evidence:manual` (W p.27)

| 규칙 | 내용 |
|---|---|
| 종류 | 政略コマンドポイント(**PCP**), 軍事コマンドポイント(**MCP**) |
| 소비 | 커맨드마다 어느 CP를 몇 점 쓰는지 정해져 있다. 소비량 0인 커맨드는 잔량과 무관하게 무제한 |
| 회복 | **게임 2시간마다(실 5분마다)** 회복. 오프라인이어도 회복. 회복량에 「政治」「運営」 능력이 영향 |
| 회복 정지 | 전술 게임 중에는 회복하지 않고, 전술 종료 시점부터 경과 시간을 센다 |
| 대용(代用) | 해당 CP가 모자라면 다른 CP를 자동 대용, **소비량 2배**. 대용분은 성장 경험치에 누적 안 됨(W p.15) |

매뉴얼에 없는 값: CP 최대치, 회복량 공식(政治·運営 가중) → `evidence:guess`. 커맨드별 CP 비용은 부록 「戦略コマンド一覧表」(W p.68–74)에 있다 → [07-command-table](07-command-table.md).

## 4. 실행 대기·소요 시간 `evidence:manual` (W p.28)

- 実行待機時間: 입력 후 실행 시작까지 걸리는 시간.
- 実行所要時間: 실행 시작부터 완료까지 걸리는 시간.
- 커맨드별 값은 부록 표(W p.68–74)와 전술 커맨드 설명(W p.53–55)에 있다.

서버 메모 `evidence:guess`: 커맨드는 "예약 → 대기 → 실행 중 → 완료" 상태를 갖는 서버측 작업(job)으로 모델링하고, 전역 게임 시계에 맞춰 진행한다.

## 5. 커맨드 군(群) `evidence:manual` (W p.28)

| 군 | 성격 | 주로 담긴 카드 |
|---|---|---|
| 作戦 | 기함 유닛 조작 관련. 전원 공통 | 艦長カード |
| 個人 | 성계 내 이동·개인 행동. 전원 공통 | 個人カード |
| 指揮 | 군사작전 입안·함대 결성 등 전반 지휘 | 작전 총괄 직책 카드 |
| 兵站 | 군수물자 투입·부대 재결성 등 함대 유지 | 艦隊司令官カード 등 |
| 人事 | 승진·강등·임명 | 인사권 직책 |
| 政治 | 국가 예산·국가 목표 등 | 국가 중추 직책 |
| 諜報 | 일제수사·체포 등 군기 유지 + 잠입공작 등 첩보 | 헌병·첩보 직책 |

## 6. 그리드 `evidence:manual` (W p.31)

- 전략 지도는 **100광년 단위 그리드.** 종류: 空間グリッド / 星系グリッド / 航行不能グリッド(진입 불가).
- 진입 제한:
  1. **유닛 수**: 한 그리드에 한 진영 **함선 유닛 300 이하**(행성 수비대 등 육전대 포함). 부대는 소속 전 유닛 몫의 여유가 있어야 진입(일부만 진입 불가).
  2. **진영 수**: 한 그리드에 **최대 2진영.** 같은 세력이라도 정규군과 반란군은 별도 진영으로 센다.
  3. **독행함(独行艦) 제한**: 독행함은 독행함 이외의 적 유닛 또는 적 행성/요새가 있는 성계 그리드에 진입 불가. 단 아군 함정 유닛이 있고 전술 중인 그리드면 예외.
  4. **지형**: 플라스마 폭풍·사르가소 스페이스가 있는 그리드는 어떤 기함/함정 유닛도 진입 불가.

## 7. 워프와 이동 `evidence:manual` (W p.32–33)

- 그리드 간 이동은 워프. **성계 그리드에 들어가려면 먼저 인접 그리드로 워프**해야 한다(원거리에서 한 번에 성계 진입 불가).
- 장거리 워프는 **워프 오차**가 생길 수 있고, 이 경우 목표 그리드에 인접한 공간 그리드 중 하나에 도착.
- 워프는 「航続」을 소비하며 **航続 100 미만이면 워프 불가.**
- 이동 계층과 담당 카드·커맨드:

| 이동 | 카드 | 커맨드 |
|---|---|---|
| 그리드 간(우주) | 艦長 | [ワープ航行] → 워프 가능 범위 표시 → 그리드 선택 → 확인 |
| 같은 성계 내 행성 간 | 艦長 | [寄港] → 행성 목록 |
| 행성 내 시설 간 | 個人 | [遠距離移動] → 시설 목록 |
| 같은 시설 내 방(스폿) 간 | 個人 | [近距離移動] → 스폿 목록 |

매뉴얼에 없는 값: 워프 가능 범위(거리), 오차 확률 공식, 航続 최대치·소비량·회복 → `evidence:guess` 또는 클라이언트 데이터에서 확인.

## 8. 서버 월드 모델 초안 `evidence:guess`

```
Galaxy ─ Grid(100ly, type: space|system|impassable, terrain) ─ StarSystem ─ Planet/Fortress ─ Facility ─ Spot
Character ─ location(Grid | Planet | Facility | Spot) , cards[≤16], PCP/MCP, 航続
Unit(旗艦/艦艇/陸戦) ─ faction(正規軍/叛乱軍 구분) ─ per-grid cap 300/faction, ≤2 factions/grid
```
