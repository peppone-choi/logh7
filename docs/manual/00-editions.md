### 2.1 개발방침 변경 공지(2004-10) 요지

- 기존: 상층부 플레이어가 게임 전체를 이끄는 설계 → 상층부 부담 과중, 개인 플레이어는 즐기기 어려움.
- 전환: 짧게 참여하거나 상층부와 엮이지 않는 플레이어도 즐길 수 있도록. 역할 분담 기본 구조는 유지.
- 그 대가로 **발표된 기능의 연기·변경, 매뉴얼 내용 변경**이 있을 수 있다고 명시. 구체적으로 **무역·개척 등 경제 행위, 페잔 외교·첩보**를 도입 연기 또는 재검토.
- 로드맵:

| 예정 | 기능 |
|---|---|
| 2004-10 | 공중전(전투정) 도입, 물자 소비(레일건·미사일·공중전 공격 시) 도입 |
| 2004-11 | 전술 AI(플레이어 부재 시 대행) |
| ~2004-12 | 제안 메일 처리 대행 기능(부재 시) |
| 2004-12 | 경비대(신기능), 채팅 강화(전체 채팅·채널) |
| 2005-02 | 기함 구매 |
| 기함 구매 다음 | 전략 수송 커맨드(수송함대 패키지 수송), 생산계 커맨드(시설·함선 건조) |

패치 리뷰(update01~05)로 경비대·채널 채팅·최고사령관 임무·기함 구매까지는 도입이 확인된다. **전략 수송·생산 커맨드의 도입 여부는 확인되지 않는다**(2005-04 서비스 종료). `evidence:manual`
