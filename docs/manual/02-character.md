# 캐릭터 능력치와 성장

## 1. 캐릭터 항목 `evidence:manual` (W p.14–15)

| 항목(원어) | 의미 | 서버 모델 메모 |
|---|---|---|
| 氏名 | 이름. 제너레이트는 자유 작명, **다른 캐릭터와 중복 불가** | 세션 내 unique 제약 |
| 性別 | 성별. 직책·능력 차이 없음 | enum |
| 生年月日 | 생년월일. 제국은 帝国暦, 동맹은 宇宙暦로 표시 | 내부는 단일 달력, 표시만 변환 `evidence:guess` |
| 分類 | 「政治家」「軍人」 2종. 전신(転身)하면 자동 변경 | enum |
| 階級 | 최하 「二等兵」~최상 「元帥」 | 계급 표는 [04-personnel](04-personnel.md) |
| 爵位 | 귀족일 때 작위(제국 한정): 公爵·侯爵·伯爵·子爵·男爵·帝国騎士 | 매뉴얼은 "5종"이라 쓰면서 6개를 나열한다(원문 불일치) |
| 出自 | 제국: 貴族·帝国騎士·平民·亡命者 / 동맹: 市民·亡命者 | 제너레이트 생성 시 선택 |
| 出身地 | 출신지. 격침 시 귀환지를 따로 정하지 않으면 여기로 자동 귀환 | 리스폰 지점 |
| 功績 | 현재 계급에서의 공적 포인트. **이 순위로 승진/강등 결정** | 계급 내 랭킹 |
| 評価ポイント | 해당 세션 안에서의 평가 | 경비함·기함 구매 화폐로도 쓰임(패치노트) |
| 名声ポイント | 세션과 무관한 플레이어 전체 평가 | 계정 단위 영속 값 `evidence:guess` |

능력치 8종 `evidence:manual` (W p.14–15):

| 능력치 | 영향 |
|---|---|
| 統率 | 인재 활용. 요직이면 징세액·정부 지지율, 함대사령관이면 함대 최대 사기·항복 권고 성공률 |
| 政治 | 시민 지지 획득 |
| 運営 | 사무 관리. 행성 통치 |
| 情報 | 첩보 활동, 전술 색적 능력 |
| 指揮 | 휘하 함선을 빠르게 움직이게 함 |
| 機動 | 함대 이동 지휘, 조함 민첩성 |
| 攻撃 | 함대 공격력(사령관/막료), 행성 방위사령관이면 행성의 대함 방위력 |
| 防御 | 함대 방어력(사령관/막료), 방위사령관이면 행성 점령에 대한 방어력 |

## 2. 성장 규칙 (웹판 신설, "잠정 사양") `evidence:manual` (W p.15)

매뉴얼이 "현재 잠정적인 사양으로 구현"이라고 밝히고 있다.

1. **나이 효과**: 젊은 캐릭터는 매월 능력치가 오를 가능성, 장년 캐릭터는 매월 내려갈 가능성. 증감 모두 일정 값까지만.
2. **경험치**: 전략 커맨드 실행에 쓴 CP가 누적되고, 일정 사용량마다 대응 능력의 경험치 중 하나가 1 오른다. 경험치 100마다 능력치 +1, 경험치는 0으로.
   - PCP 사용 → 統率·政治·運営(원문 표기 "運用")·情報 중 하나
   - MCP 사용 → 指揮·機動·攻撃·防御 중 하나
   - **CP 대용(代用)으로 소비된 CP는 누적되지 않는다.**

매뉴얼에 없는 값(`evidence:guess` 로 정해야 함): "젊은/장년"의 나이 경계, 월간 변화 확률과 폭, 상·하한, "일정 사용량"의 크기, 경험치를 받을 능력치 선택 방식(무작위/가중).

## 3. 서버 구현 메모 `evidence:guess`

- 월 단위 성장 처리는 게임 시간 1개월(= 실 30시간) tick 이벤트.
- CP 사용 로그를 PCP/MCP 별로 누적하는 카운터가 캐릭터에 필요.
- 클라이언트가 표시하는 능력치 범위·자리수는 클라이언트 UI 리소스/패킷 구조로 확인해 상한을 정한다(트랙 B 산출물 참조).
