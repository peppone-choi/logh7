# 전략 커맨드 전체 표 (81개)

- 원자료: 웹판 부록 p.68–74. 수치(CP·대기·소요)는 [data/strategy-commands.csv](data/strategy-commands.csv) 가 추출 원본이고, 아래 설명은 해설을 한국어로 줄여 쓴 것이다. `evidence:manual`
- **CP 종류(PCP/MCP) 구분은 표에 없다.** 커맨드 군과 성장 규칙(PCP→統率·政治·運営·情報, MCP→指揮·機動·攻撃·防御)으로 보아 작전·지휘·병참 = MCP, 개인·인사·정치·첩보 = PCP 로 **추정**한다. `evidence:guess` — 클라이언트 데이터로 확인할 것(트랙 B).
- **대기·소요 시간의 단위도 표에 없다.** 같은 표의 다른 설명이 「G分」「G日」을 쓰는 점, 24 = 게임 1일이라는 점에서 게임 시간(G시간)으로 **추정**. `evidence:guess`
- 상태 열: `구현`(매뉴얼상 동작 규칙 존재) / `미구현`(매뉴얼·공지가 미구현·연기로 명시) / `불명`(설명만 있고 연관 시스템이 미구현·미기재) / `패치`(패치로 추가).
- **이 표의 상태는 원작 자료의 상태이며 현재 대체 서버의 구현 완료 표시가 아니다.** 현재 서버 연결 여부는 요청 처리·상태 변경·저장·원본 UI 확인을 별도로 대조한다. 커맨드 이름이나 규칙 클래스가 있다는 이유만으로 실행 가능으로 세지 않는다.
