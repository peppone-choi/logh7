# 전략 커맨드 전체 표 (81개)

- 원자료: 웹판 부록 p.68–74. 수치(CP·대기·소요)는 [data/strategy-commands.csv](data/strategy-commands.csv) 가 추출 원본이고, 아래 설명은 해설을 한국어로 줄여 쓴 것이다. `evidence:manual`
- **CP 종류(PCP/MCP) 구분은 표에 없다.** 커맨드 군과 성장 규칙(PCP→統率·政治·運営·情報, MCP→指揮·機動·攻撃·防御)으로 보아 작전·지휘·병참 = MCP, 개인·인사·정치·첩보 = PCP 로 **추정**한다. `evidence:guess` — 클라이언트 데이터로 확인할 것(트랙 B).
- **대기·소요 시간의 단위도 표에 없다.** 같은 표의 다른 설명이 「G分」「G日」을 쓰는 점, 24 = 게임 1일이라는 점에서 게임 시간(G시간)으로 **추정**. `evidence:guess`
- 상태 열: `구현`(매뉴얼상 동작 규칙 존재) / `미구현`(매뉴얼·공지가 미구현·연기로 명시) / `불명`(설명만 있고 연관 시스템이 미구현·미기재) / `패치`(패치로 추가).
- **이 표의 상태는 원작 자료의 상태이며 현재 대체 서버의 구현 완료 표시가 아니다.** 현재 서버 연결 여부는 요청 처리·상태 변경·저장·원본 UI 확인을 별도로 대조한다. 커맨드 이름이나 규칙 클래스가 있다는 이유만으로 실행 가능으로 세지 않는다.

## 판정 메모

- `불명` 커맨드는 **클라이언트에 UI·패킷이 있는지**(트랙 B)와 **원 서비스에서 실제 동작했는지**(커뮤니티 기록, 트랙 C)를 교차 확인해 P3(핵심 루프)과 P5(미구현 기능)로 나눈다.
- 매뉴얼에 규칙은 있으나 수치가 없는 항목(영향력·우호도·치안유지율·지지율·훈련도 등)은 [unimplemented-candidates](unimplemented-candidates.md) 의 "수치 미기재" 목록으로 관리한다.

원표 81개를 카드 노출→Gateway 요청→엔진 효과→저장 경로와 기존 원본 실행 기록으로 대조했다. 제한 연결 14개, 실행 미연결 67개다. 67개 중 메뉴만 존재하는 4개와 독립 규칙만 있는 6개도 실행 미연결로 센다. 이 수치는 완성률이 아니다. 14개도 전체 권한·예약·실패·세력 조합을 마친 것이 아니며, 이번 감사에서 81개를 원본으로 재실행한 것은 아니다.

| 명령군 | 제한 연결 | 실행 미연결 |
|---|---:|---:|
| 작전 | 5 | 11 |
| 개인 | 2 | 13 |
| 지휘 | 0 | 8 |
| 병참 | 4 | 2 |
| 인사 | 3 | 7 |
| 정치 | 0 | 12 |
| 첩보 | 0 | 14 |

현재 연결 경로는 `server/gateway/.../GameExchange.kt`의 워프 `0b01`, 연료 `0b02`, 기항 `0b00`, 시설/스폿 `0e00`, 전략 육전대 승하선 `0b04/0b05`, 완전 보급 `0c01`, 재편성 `0c02`, 보충 `0c05`, 할당 `0c0b`, 임명/해임/사임 `0707/0708/0709`다. 효과는 `Navigation`, `FleetNavigation`, `GroundTransfer`, `CompletenessSupply`, `Reorganization`, `Supplement`, `StockAssignment`, 직위 정책 및 `WorldEngine`의 저장 커밋에서 확인했다. 전략 육전대 승하선은 함장 카드 목록이 아니라 부대 정보창의 전체 승하선 경로다. 기항은 원표의 성계 내 항행과 원본 카드의 寄港 사이 대응이며 모든 성계 내 이동 규칙 완료를 뜻하지 않는다.

`WorldMessages.commands`는 함장 카드에 육전 훈련·육전 전술 훈련·무력 진압·지원을 노출하지만 해당 실행 효과가 없다. 작전 계획/철회/발령 및 승진/발탁/강등의 순수 판정 클래스도 사용자 요청 실행에 연결되지 않았다. `StrategyCatalog`의 이름/비용 81개와 `StrategyPipeline`의 공통 예약 규칙을 81개 실행 구현으로 세지 않는다. 미지원 요청은 범용 성공 응답이 아니라 `Unsupported game opcode` 경로로 끝날 수 있어, 메뉴만인 항목의 원본 요청/거부 처리를 후속 구현에서 확인해야 한다.

세율 변경·출항은 원표 81개 밖의 추가 연결이며 위 14개에 더하지 않았다. 자동 생산·NPC 전투·일일 국고 정산도 사용자 정치/작전 명령의 구현을 대신하지 않는다. 특히 납입률 변경·분배·완전 수리·부대 결성/해산·기함 구매·작위/봉토·정치/첩보 명령은 후속 작업으로 남는다. 개별 실제 확인 범위는 기존 [플레이 체크리스트](../IMPLEMENTATION-CHECKLIST.md)와 각 연결 문서를 따른다.
