# 세션·시간·접속·승패 규칙

표기: `W p.N` = 웹판 PDF 페이지, `CD p.N` = CD 동봉판 PDF 페이지. 인쇄 쪽번호가 아니라 PDF 페이지 번호다.

## 1. 게임의 성격

- 원작 소설의 세계에서 플레이어가 **캐릭터 1명**이 되어 제국 또는 동맹 조직에 들어가 출세하며 소속 진영의 승리를 노리는 다인원 온라인 전략 시뮬레이션. 원칙적으로 모든 캐릭터를 사용자가 맡는다. `evidence:manual` (W p.5)
- 구성은 **전략 게임**(국가 운영·생산·이동·인사)과 **전술 게임**(RTS형 실시간 함대전·점령) 두 모드. 전술은 적 유닛과 같은 그리드에 들어가면 시작되고 한쪽 세력만 남으면 끝난다. 전술 중인 캐릭터는 전략 커맨드를 입력할 수 없다. `evidence:manual` (W p.9, p.12)
- 매뉴얼 스스로 "경제 관련은 현재 미구현"이라고 적고 있다(徴税 등 세금 경제). `evidence:manual` (W p.9) → [미구현 후보](unimplemented-candidates.md) U-02

## 2. 로그인·서버 선택·로그아웃

| 항목 | 규칙 | 근거 |
|---|---|---|
| 인증 | 「ID」「パスワード」 입력(β 등록 시 메일로 발급) | `evidence:manual` W p.8 |
| 서버 선택 | 로그인 화면에서 플레이할 서버를 고른다. **서버 하나에 제국/동맹 중 한 진영 데이터만** 만들 수 있다 | `evidence:manual` W p.8 |
| 오프라인 지속 | 로그아웃해도 캐릭터는 서버 안에서 계속 존재한다 | `evidence:manual` W p.8 |

로그아웃 위치별 효과 `evidence:manual` (W p.8):

| 위치 | 전사 | 체포 | 인사 대상 | 비고 |
|---|---|---|---|---|
| 자택/호텔(거실)/거주구(거실) | 없음 | 가능 | 됨 | 다른 장소로 이동되지 않음 |
| 기함 유닛 안(행성·요새에 **주류(駐留)** 중) | 없음 | 가능 | 됨 | 오프라인 중 함락되면 주류 상태가 풀릴 수 있음 |
| 기함 유닛 안(우주 공간) | 전술 발생 시 AI가 대행한다고 되어 있으나 **AI는 미구현**으로 명기 | 가능 | 됨 | → U-01 |
| 그 밖의 장소 | — | — | — | 원칙적으로 그 자리에 계속 있음 |

서버 구현 메모 `evidence:guess`: 오프라인 캐릭터도 월드 상태에 남아 체포·인사·전투 대상이 되므로, 세션 상태는 접속 여부와 무관하게 서버가 소유해야 한다(서버 권위).

## 3. 세션

- 같은 호스트에 접속한 사용자가 공유하는 가상 공간을 「セッション」이라 부른다. 모든 커맨드는 서버가 처리해 결과를 돌려준다. `evidence:manual` (W p.10)
- **세션당 최대 2,000명.** `evidence:manual` (W p.10)
- 복귀 제한: 사망 등으로 세션에서 제외된 플레이어가 같은 세션에 재등록하면 ① 원작 캐릭터로는 복귀 불가 ② 제외 당시 소속 진영으로만 복귀. `evidence:manual` (W p.10)
- 종료: 아래 승패 조건에 도달하면 자동 종료, 원칙적으로 초기 조건에서 재시작. `evidence:manual` (W p.10)

## 4. 시간

- 실시간 진행, **게임 시간 = 실시간 × 24.** (실 1초 = 게임 24초, 실 1시간 = 게임 1일, 실 30시간 = 게임 1개월) `evidence:manual` (W p.10)
- 전술 게임도 같은 시간 흐름. 어디서 전술이 시작돼도 다른 플레이어의 시간은 멈추지 않는다. `evidence:manual` (W p.10)
- 패치노트의 시간 단위 표기 "24G分", "4G時間" 등은 게임 내 시간(G)을 뜻하는 것으로 보인다. `evidence:guess` (update04)

서버 구현 메모 `evidence:guess`: 전략·전술을 하나의 전역 게임 시계로 돌리는 tick 엔진이 필요하다. 월 단위 이벤트(능력치 성장 등)는 실시간 30시간 주기.

## 5. 캐릭터 종류와 이월

| 구분 | 규칙 | 근거 |
|---|---|---|
| 오리지널 캐릭터(原作キャラ) | 능력치 사전 설정. 캐릭터별 **담당 조건** 심사를 통과해야 응모 가능, 경합 시 **추첨**. 다음 세션으로 **이월 불가** | `evidence:manual` W p.11 |
| 제너레이트 캐릭터 | 규칙 범위 안에서 능력치 배분, 이름·얼굴 CG 자유. 원칙적으로 해당 세션 전용 | `evidence:manual` W p.11 |
| 이월 | 세션에서 **일정 이상의 평가 포인트**를 얻은 제너레이트 캐릭터는 다음 세션으로 나이·능력치·계급을 가져간다. **60세 도달 전까지만** | `evidence:manual` W p.11 |
| 미선택 원작 캐릭터 | AI가 담당한다고 되어 있으나 **AI 미구현** 명기 | `evidence:manual` W p.11 → U-01 |
| 캐릭터 삭제(웹판 신설) | 제너레이트 캐릭터는 ① 계급 대령 이하 ② 거주구/호텔 자기 방에 있음 ③ 연료보급·전략색적 등 지속 효과 중이 아님 — 을 모두 만족하면 삭제 후 재작성·추첨 가능 | `evidence:manual` W p.12 (CD판 목차에 없음) |

이월 기준이 되는 "일정 이상"의 수치는 매뉴얼에 없다. `evidence:guess` 로 정해야 한다.

## 6. 승패

종료 조건(하나라도 충족 시) `evidence:manual` (W p.12):

1. 적 세력의 수도 행성을 점령
2. 제국/동맹 정규군 진영의 지배 성계가 수도 성계 포함 **3개 이하**
3. **우주력 801년 7월 27일 00:00**까지 위 두 조건이 성립하지 않음(시간 제한)

평가 4단계 — 결과에 따라 세션 종료 시 얻는 공적 포인트가 달라진다 `evidence:manual` (W p.12–13):

| 평가 | 조건 |
|---|---|
| 決定的勝利 | 세션 인구 90% 이상 지배 · 적과 함정 유닛 수 비 10배 이상 · 종료 시 쿠데타 미발생 · (제국만) 종료 시 황제 또는 제국군 최고사령관 카드 보유자가 적 수도 성계에 있음 — **모두** 충족 |
| 限定的勝利 | 결정적 승리 조건 중 하나라도 미충족 |
| 局地的勝利 | 적 수도 점령 이외의 사유로 종료되고 세션 인구 비율에서 앞섬. 동수면 동맹의 국지적 승리 |
| 敗北 | 위 승리 조건 모두에 미달 |

평가 등급별 공적 포인트 수치는 매뉴얼에 없다(`evidence:guess` 필요). "쿠데타" 발생 규칙도 이 매뉴얼 범위에서는 조건이 설명되지 않는다 → 미구현 후보 U-10 참고.
