## 기준 (CLAUDE.md §5)

1. **1차: 소설 『은하영웅전설』 이타카판(김완 역, 2011~; 2025 GC북스 리뉴얼판 동일 번역)** — 인명·지명·계급·직책.
2. **보조: 1988년작 OVA의 한국어 더빙판(1992 대원동화 대여 비디오)** — 1차에 없는 용어만. (DNT 판 아님. TV 방영·정식 자막판은 없음)
3. 둘 다 없으면 이 문서에서 제안하고 `evidence:guess` + **확인 필요**로 표시.
4. 게임 고유 시스템 용어는 원작 소설에 없으므로 이 문서의 제안안을 쓴다(`evidence:guess`), 사용자 확정 후 `확정`으로 바꾼다.

표기 열: `원어` · `제안 한국어` · `근거` · `상태(확정/제안/확인 필요)`.

## 3. 원작 용어 — 판본 사실과 확정 상태

판본(glossary-sources.md §1, `evidence:web`):
- **1차 기준 = 이타카판(레이블 이타카, 디앤씨미디어, 김완 역, 2011~)**. 2025년 GC북스 리뉴얼판은 같은 번역이다.
- **보조 기준 = 1988년 제작 OVA 본편 1~26화의 한국어 더빙판(1992, 대원동화 대여 비디오)**. TV 방영·정식 자막판은 없다. 이 더빙판의 표기 목록은 찾지 못해 보조 기준 열은 현재 전부 공란이다.
- 넷마블 「은하영웅전설 온라인」(2004 CBT) 한국어 클라이언트가 확보되면 게임 UI 용어의 참고로 추가한다.

## 4. 확인 대기 목록 (사용자 확인 필요, Linear LOGH-38)

1. 이타카판(또는 GC북스판) 실물·전자책으로 §3.2 후보 대조 — 특히 주요 인물 성명 전체 표기, 계급 전체, 직책명.
