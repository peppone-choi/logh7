# 한국어화 용어집

작성자: 최병호 · 갱신: 2026-10-18 · LOGH-38

## 적용 기준

- 사용자 결정 D-4에 따라 일본어 직역과 나무위키 검색 표기를 현재 작업 기준으로 채택한다. 이타카판 실물 대조는 보류한다. `evidence:guess`(번역 정책; AGENTS.md §5).
- 원어의 게임 내 존재는 매뉴얼 근거, 한국어 번역의 선택은 설계 정책이다. 번역 열의 `채택`은 작업 표기 확정이며 원작 번역본 대조 완료를 뜻하지 않는다. `evidence:manual` / `evidence:guess`.
- 인물·지명 표기는 기존 [출처 조사](glossary-sources.md)의 나무위키 후보를 승계했다. 2026-10-18 재조회에서 나무위키 용어·등장인물·지명·세력·함선 문서 본문을 추출해 일부 표기 문자열을 확인했다. 확인·미발견 목록은 [출처 조사 §10](glossary-sources.md#10-2026-10-18-나무위키-재조회)에 둔다. 미발견은 추출 범위 한계일 수 있으며 표기 오류 판정이 아니다. `evidence:web`(확인분) / `evidence:guess`(승계분).
- 아래 나무위키 링크는 제3자 한국어 표기 출처다. 게임의 기능·계급 수·직무 권한을 입증하는 매뉴얼 근거와 구분한다. `evidence:guess`.

### NPC 초기 담당자 명단 70명

2026-10-27 사용자 요청으로 NPC 편집기의 초기 담당자 이름 70개와 계급을 한글로 표시한다. 실행에 쓰는 대응의 단일 원천은 [npc-names.ko.json](../../l10n/npc-names.ko.json)이다. 기존 주요 인물 표기의 별칭을 연결하고, 추가 인물은 나무위키 [등장인물](https://namu.wiki/w/은하영웅전설/등장인물)·[기타 등장인물](https://namu.wiki/w/은하영웅전설/기타%20등장인물)을 기준으로 채택했다. 나무위키 직접 열람은 실패하여 [등장인물 미러](https://d.namu.moe/w/은하영웅전설/등장인물)와 [기타 인물 미러](https://namu.moe/w/은하영웅전설/기타%20등장인물)의 표기·검색 결과를 대조했다. 얼굴 매칭·게임 능력치의 근거가 되는 자료는 아니다. `evidence:guess`(번역 선택)

원작의 일본어 약칭을 보존하며 대응을 확인한 경우 한국어 이름을 풀어 쓴다(예: `G.ミュッケンベルガー` → 그레고르 폰 뮈켄베르거, `D.グリーンヒル` → 드와이트 그린힐). 다음 7개는 임시 한글 표기를 적용하고 `pending`으로 남긴다. 기존 명단이나 화면을 일본어로 남겨 두는 뜻은 아니다.

사용자가 추가 제공한 [이름별 분류](https://namu.wiki/w/은하영웅전설/등장인물%20이름별%20분류)도 [미러](https://namu.moe/w/은하영웅전설/등장인물%20이름별%20분류)로 열람했다. 황 루이·우란푸·응웬 반 티우·랄프 칼센·윌렘 홀랜드 등 표기와 이름 구성을 교차 확인했지만 아래 7개의 미해결 대응을 새로 확정할 내용은 찾지 못했다. 이름 계통에서 얼굴·능력·게임 내 출신을 유도하지 않는다.
